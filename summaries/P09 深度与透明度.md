# P09 深度与透明度

## 一句话概括

本集为软件光栅化器补上最后两块拼图：用深度缓冲区（depth buffer / Z-buffer）以逐样本、常数代价的方式解决遮挡，用 alpha 与 over 运算符处理半透明，并最终把整条光栅化管线与真实 GPU 硬件对应起来。

## 本集主题与目标

课程此时已经讲过三维变换、透视投影、三角形光栅化、重心坐标属性插值和纹理采样。但这些都是"把单个三角形画出来"，还没有回答一个根本问题：当许多三角形都投影到同一块屏幕上时，每个采样点最终应该显示哪一个？本集的目标就是完成光栅化流程的最后一步——把每个图元产生的样本合并成最终图像，同时正确处理深度（遮挡）与透明度（半透明叠加）。

讲师把问题拆成两半：先处理完全不透明三角形的遮挡，再处理半透明表面。前者引出深度缓冲，后者引出 alpha 合成与预乘 alpha（premultiplied alpha）。最后用一段完整的管线回顾把前几集的内容串起来，并说明课堂上写的软件光栅化器与 OpenGL、现代 GPU 的关系。

## 核心概念

**深度缓冲 / Z 缓冲区（depth buffer, Z-buffer）**：为每个采样点额外保存一个"目前见过的最接近观察者的深度值"，初始化为无穷大或可表示的最大值。绘制新样本时，先比较它的深度与缓冲区中的值，更近才写入颜色并更新深度。它重要是因为让遮挡判断不再依赖三角形的绘制顺序，从而把"排序所有图元"这个全局难题降级为"每个采样点做一次比较"这个局部操作。

**深度测试（depth test）**：核心只有一句判断——新样本深度 $d$ 是否小于该位置已存的深度。通过则说明当前三角形在该点更靠前，写入颜色与深度；失败则说明已有更近的物体，直接丢弃。它是整个深度缓冲算法唯一的新增逻辑，代价是常数时间的一次读、一次比较、可能的一次写。

**逐样本而非逐图元（per-sample vs. per-primitive）**：光栅化管线一次只处理一个三角形，算完就丢弃，不保留整个场景的图元列表。这本是管线最大的优势（流水线、低内存），却也让"谁在前面"看似无法判断。深度缓冲的巧妙之处在于把比较放在采样点层面：两个相交三角形在不同像素上谁前谁后可以不同，逐样本比较自然得到正确结果。

**重心坐标插值深度**：已知三角形三个顶点的屏幕坐标与各自深度，可以用重心坐标在三角形内部插值出任意采样点的深度。讲师在上节课已用同一套机制插值颜色和纹理坐标，这里只是把被插值的属性换成深度，因此几乎不需要新代码。

**超采样与深度缓冲的结合**：超采样（supersampling）为每个像素保留多个颜色样本以抗锯齿。若同时使用深度缓冲，就必须为每个子样本各配一个深度值，而不是每个像素共用一个。这样不同子样本可以命中不同深度的三角形，最后再平均颜色，边缘仍然平滑；否则深度会"张冠李戴"，产生错误遮挡。

**Alpha / 不透明度**：用一个 $[0,1]$ 的实数描述表面有多不透明，$\alpha=1$ 完全不透明，$\alpha=0$ 完全透明。这是对玻璃、水等真实透明现象的极度简化——真实材质还需要折射率、吸收、散射等参数，但当前阶段只需要"能透过多少比例的背景"这一个量。每个像素可以有自己的 alpha，便于把抠好的前景（如树叶、考拉照片）叠到背景上。

**Over 运算符**：把图像 B 叠加到图像 A 之上的合成操作。直觉是"有色玻璃"：B 越不透明，结果越偏 B 的颜色；B 越透明，透出的 A 越多。它不满足交换律，$A\ \mathrm{over}\ B \neq B\ \mathrm{over}\ A$，因此绘制顺序本身携带信息，这也是后面半透明排序问题的根源。

**预乘 alpha（premultiplied alpha）**：不单独存颜色 $a$ 和 alpha，而存 $a'=\alpha_a a$，即"已经被 alpha 暗化过的颜色"，同时保留 alpha 通道。合成时 $c' = b' + (1-\alpha_b)a'$，颜色与 alpha 走完全相同的线性运算。它的优势是：实现统一、运算更少、重复合成封闭、滤波（上采样/下采样）不产生边缘伪影，而且天然契合齐次坐标与 GPU 的混合硬件。

**边缘伪影 / 暗色光环（fringe / halo）**：非预乘 alpha 在滤波或合成时，透明像素的 RGB 仍带有颜色（例如绿幕的绿色），这些"看不见的颜色"会被插值进边缘，与背景合成后形成绿色或暗色描边。预乘 alpha 把透明区域的颜色乘成黑色，插值时只贡献"黑+零 alpha"，反预乘后就不会污染边缘。

**合成的封闭性（closure）**：反复做 over 运算后，结果仍能用同一种表示描述。预乘 alpha 满足封闭性：两个半透明红色叠加，颜色仍是纯红、只有 alpha 增大；非预乘表示则会把颜色和透明度混在一起，出现"变暗"的失真。这一点对场景中大量半透明元素逐层绘制非常关键。

**顺序无关透明度（order-independent transparency, OIT）**：不排序也能正确合成半透明的技术方向。字幕提到深度剥离（depth peeling）以及用 alpha 缓冲区为每像素存一个值列表的思路；后者数据量随样本数变化、无法连续存储，在 GPU 上不实用。讲师的态度很明确：光栅化管线处理半透明很痛苦，这是光线追踪的优势之一。

**完整光栅化管线**：输入是顶点坐标、UV、纹理、模型到相机的变换、投影方式、图像尺寸；每个三角形依次经过相机变换、透视投影、裁剪、齐次除法、视口变换、光栅化、属性插值、纹理采样、深度测试、写颜色缓冲。它是本集的收束，也是理解 GPU 固定功能阶段的骨架。

## 关键公式 / 算法 / 数据结构

深度插值（重心坐标）：

$$d(x,y) = \lambda_i d_i + \lambda_j d_j + \lambda_k d_k,\qquad \lambda_i+\lambda_j+\lambda_k=1$$

深度测试与写入（伪代码）：

```text
for each sample (x, y) with depth d and color c:
    if d < depthBuffer[x][y]:        # 更近
        colorBuffer[x][y] = c
        depthBuffer[x][y] = d
    else:
        discard                       # 已有更近的物体
```

非预乘 alpha 的 over：

$$c = \alpha_b\, b + (1-\alpha_b)\,\alpha_a\, a,\qquad
\alpha_c = \alpha_b + (1-\alpha_b)\,\alpha_a$$

预乘 alpha 的 over：

$$a' = \alpha_a a,\quad b' = \alpha_b b,\quad
c' = b' + (1-\alpha_b)\,a',\quad
\alpha_c = \alpha_b + (1-\alpha_b)\alpha_a$$

反预乘恢复颜色：

$$c = \frac{c'}{\alpha_c}$$

数据结构：颜色缓冲区每样本 3 个分量（RGB），深度缓冲区每样本 1 个分量；使用超采样时按子样本数成倍增加，但增量是与重叠图元数量无关的常数空间。alpha 缓冲区（每像素存多个半透明片段）只是被提及的方案，未被采用。

## 讲解脉络

**第一节，定位与回顾。** 讲师先退一步，把光栅化管线描述为"输入三角形与属性 → 若干阶段 → 位图"的黑箱，指出变换、投影、光栅化、属性插值、着色都已讲过，今天只差"如何把每个图元产生的样本合并成最终图像"。这个开场把新问题牢牢挂在已有管线的末端，避免学生把深度缓冲当成孤立技巧。

**第二节，遮挡问题与深度插值。** 先假设三角形不透明，问"每个样本点可见哪个三角形"。由于顶点深度已知，用上节课的重心坐标插值即可得到任意点的深度，讲师强调这是"同一套工具换一个属性"，成本极低。这一步先解决"能不能算深度"，再解决"怎么用深度"。

**第三节，深度缓冲算法与顺序无关性。** 这是本集的核心。讲师用黄、蓝、第三个三角形的灰度示意逐步演示：初始化无穷大、逐个样本比较、通过则写颜色并更新深度。随后故意埋了一个悬念——"我选的顺序很特殊，顺序真的无关吗？"——再解释因为比较发生在采样点层面，三角形相交也能逐点得到正确的前后关系；反之若要求按图元从后往前排序，就得求交、切分多边形，复杂度陡增。

**第四节，鲁棒性与超采样。** 讨论深度缓冲与超采样的交互：结论是只要每个子样本配一个深度就完全可行，最后照常平均颜色。讲师顺势总结空间代价——每样本多一个标量，与图元数量无关；时间代价——每样本一次比较，常数时间，不需要维护有序列表。还补充说深度缓冲并不限于三角形，只要能求深度的物体（如球体）都可直接光栅化。

**第五节，半透明模型与 over。** 从"如何描述半透明"开始，引入单参数 alpha，说明这是对真实透明的简化。接着用"红玻璃叠黄玻璃"建立 over 的直觉，强调不可交换，并给出第一次尝试的公式（非预乘），同时指出新 alpha 的一种写法会带来边缘伪影。

**第六节，预乘 alpha 与滤波。** 这是本集第二个技术高点。讲师先定义 $a'=\alpha_a a$，给出更简洁的 over 公式，指出颜色与 alpha 走同一套运算，并把它类比为齐次坐标（除以 alpha 相当于透视除法）。然后用上采样（蓝块放大小图，非预乘出现绿边、预乘干净）和下采样（树叶纹理边缘，非预乘得到浑浊棕色、预乘得到明亮绿色）两个例子，直观展示预乘表示为何在滤波时更正确。最后用两个 50% 红色叠加的例子说明预乘的封闭性。

**第七节，混合绘制策略。** 回到"半透明三角形怎么写深度"的问题，指出 over 隐含"B 在 A 之上"，因此必须按从后到前绘制，而全局排序在 GPU 上既麻烦又无法处理相交图元。于是给出工程折中：先任意顺序画不透明物体并正常更新深度；再关闭深度写入，按从后到前画半透明物体，只做深度测试、只混合颜色。讲师也提到 alpha 缓冲区、depth peeling 等顺序无关方案，并预告光线追踪没有这个烦恼。

**第八节，完整管线与硬件收束。** 讲师列出完整输入，逐个阶段复盘：相机变换、投影、裁剪、齐次除法、视口变换、光栅化、属性插值、纹理采样、深度测试、写缓冲。随后把课堂管线对应到 OpenGL 与 GPU：顶点处理、图元装配、光栅化、片元混合；并说明 GPU 是异构多核处理器，纹理双线性过滤、三角形裁剪、混合都有专用硬件，即使 CUDA/OpenCL 也只用到芯片的一部分。最后指出现代 GPU 越来越可编程、阶段间可反馈，并已加入专用光线追踪单元。

## 重点结论

1. 遮挡问题的正解不是排序图元，而是逐采样点保存"最近深度"。深度缓冲把全局排序问题转化为局部比较，顺序无关、常数空间、常数时间。
2. 深度可以在三角形内用重心坐标插值；它与颜色、UV 共用同一套插值机制，因此实现成本极低。
3. 深度缓冲与超采样可以共存，前提是每个子样本都有独立的深度值，否则边缘会出现错误遮挡。
4. 半透明的正确合成依赖顺序：over 不可交换，必须从后到前。工程上的标准做法是"不透明先画并写深度，半透明后画、测试但不写深度"。
5. 预乘 alpha 在合成、滤波、重复叠加三方面都优于非预乘：运算统一、无边缘光晕、表示封闭。它是纹理管线与 GPU 混合的默认语言。
6. 光栅化管线一次只处理一个三角形，这个"流式"特性既是性能来源，也是半透明处理的麻烦来源；顺序无关透明度仍是难题，而光线追踪天然回避了排序。
7. 课堂实现的管线与真实 OpenGL/GPU 高度同构，差别主要在硬件化、可编程性和规模。

## 字幕含糊或可能有误的地方

- **"深度值在三角形内是线性变化"**：严格说，屏幕空间的 $z$ 并不是线性插值，线性的是 $1/z$（透视校正插值）。用重心坐标直接插值深度只在正交投影或近似下成立。字幕这句话可能是讲师的简化，也可能是转写省略了"屏幕空间/透视校正"的限定，建议按透视校正理解。
- **"深度测试只是判断 d1 是否小于 d2"**：表述不完整。应是"新样本深度小于缓冲区中已存深度则通过"，字幕没有说清哪个是新的、哪个是旧的，容易误解为任意两值比较。
- **"所有样本都通过深度测试"（蓝色三角形段）**：前文刚说"只有部分标记红点的样本通过"，紧接着又说"该三角形的其他样本仍比无穷大值更近但比黄色更远"，语义自相矛盾。按上下文应理解为：蓝色三角形只有部分样本通过，其余被黄色遮挡。
- **非预乘叠加例子中的数字**：字幕出现"0.7500 透明度混合为 0.5 加 (1-0.5) 乘 0.5 等于 0.75"以及"呈现 75% 亮度的暗红色"，颜色与 alpha 的数值被混在一起念，$0.75$ 既像颜色又像 alpha。应区分：颜色通道为 $0.5\times1 + 0.5\times0.5\times1 = 0.75$，alpha 为 $0.5+0.5\times0.5=0.75$，两者数值恰好相同但含义不同。
- **"预乘透明度" / "透明度" 混用**：alpha 严格说是"不透明度"（opacity），字幕反复说"透明度为 0.5"其实指半透明、alpha=0.5。术语应统一为 alpha 或不透明度，否则"透明度越大越不透明"会自相矛盾。
- **"金属材质图"**：上下文在讲为带 alpha 的纹理构建滤波层级（mipmap），"金属材质图"很可能是 "mipmap" 或 "纹理金字塔" 的误识别，与金属材质无关。
- **"颜色视为不同方向不同透明度的颜色作为该方向上的点"**：齐次坐标类比这句转写严重断裂，原意大概是把 $(r,g,b,\alpha)$ 看作四维空间中的点、除以 alpha 相当于投影到三维颜色空间，但字幕几乎无法还原，只能按齐次除法的直觉理解。
- **"X i y i x j y j 和 x k y k"**：顶点记号被转写成零散字母，应为 $(x_i,y_i)$、$(x_j,y_j)$、$(x_k,y_k)$ 及对应深度 $d_i,d_j,d_k$。
- **"明白四分之三、二分之一、四分之一"**：此处是讲师举例 alpha 递减，转写把"比如"识别成"明白"，属于断句噪声。
- **"深度缓冲与超采样的交互如何"**：缺谓语，应为"深度缓冲与超采样如何交互"。

## 与前后集的衔接

本集直接承接上一集的重心坐标插值、超采样与纹理采样：深度只是"换一个属性来插值"，超采样只是"每个子样本各存一份深度"，纹理滤波的讨论则为预乘 alpha 的边缘伪影埋下伏笔。同时它收束了整个光栅化单元——从变换、投影、裁剪到光栅化、着色、混合，构成一条完整管线。
