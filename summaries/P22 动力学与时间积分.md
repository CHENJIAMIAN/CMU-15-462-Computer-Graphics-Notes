# P22 动力学与时间积分

## 一句话概括

本集从"怎么让物体动起来"出发，把基于物理的动画归结为求解构型 $q(t)$ 的常微分方程（ODE），用拉格朗日力学写出运动方程，再系统比较前向欧拉（会爆炸）、后向欧拉（稳定但阻尼）、辛欧拉（几乎守恒能量）等时间积分器，最后讨论导数怎么算：手动、数值、自动、符号与几何微分五条路。

## 本集主题与目标

上一集讲的是关键帧插值（keyframe interpolation）加样条插值，属于"半自动"流程：仍然要美术手动摆出每个关键姿态，每个骨骼都有一堆控制手柄和参数，劳动量巨大。本集的另一条路线是**基于物理的模拟（physics-based simulation）**：只设定初始条件和关键物理事件，然后"点击运行"，让计算机推演所有（伪）物理行为，动画自然生成。

讲师的定位很清楚：动画有两种描述——运动学（kinematics）只关心物体怎么动，动力学（dynamics）关心是什么力导致它动。本集走后者，用牛顿第二定律一类的微分方程描述运动，再用**时间数值积分（numerical time integration）**去近似求解。

与蒙特卡洛积分（Monte Carlo integration，估计曲线下面积）不同，这次是"随时间步进"的数值积分。讲师反复强调的回报是：**极其简单的模型也能涌现出复杂而优美的行为**，这正是粒子系统、群集、布料、头发等技术在电影和游戏里普遍使用的理由。

## 核心概念

- **运动学 vs 动力学（kinematics vs dynamics）**：运动学只说"物体要在这些时刻到达这些位置"，不解释原因；动力学要写出力、质量、加速度之间的关系。关键帧插值就是纯运动学的。重要性在于——它决定了我们能否"不手摆关键帧"就得到动画。

- **广义坐标（generalized coordinates）$q$**：描述系统当前状态的所有变量的长向量。台球桌 6 个球只需 12 个坐标（每个球 x、y）。直觉上，我们不再把系统看成若干条独立轨迹，而是看成**高维空间中的一条曲线**。这样做的原因很实际：计算机求解器天然就吃一个长向量、吐一个新向量，而且"追踪一条曲线"的算法与维度无关。

- **广义速度（generalized velocity）$\dot q$**：$q$ 的时间导数，可以理解为那条曲线在 $q$ 空间的切向量。

- **约束（constraints）**：形如 $g(q)=0$ 的规则，比如过山车必须待在轨道上、单摆末端必须在单位圆上。约束是让问题从"抛石头"变难的关键，也是拉格朗日方法大显身手的地方。

- **常微分方程（ODE）**：只含时间导数的方程，形式为 $\dot q = f(q, \dot q, t)$。与之相对，偏微分方程（PDE）同时含时间和空间导数，讲师明确说留到后面讲。

- **拉格朗日力学（Lagrangian mechanics）**：先写动能 $T$ 和势能 $V$，再取拉格朗日量 $L=T-V$，代入欧拉-拉格朗日方程自动得到运动方程，完全不用画受力图（force diagram）。它的优势是：标量能量比矢量力好构造（不需要考虑方向和坐标系）；对任意广义坐标通用；并且直接导向一套优秀的数值方法。

- **单摆与双摆、混沌（chaos）**：单摆方程没有闭合解；双摆更狠，初值极微小变化会导致轨迹完全不同，即混沌系统。这解释了为什么必须上数值模拟。

- **粒子系统与群集（particle systems / flocking）**：鸟群由 Craig Reynolds 的经典模型描述，力包括分离（separation，别靠太近）、对齐（alignment，跟随邻居方向）、凝聚（cohesion，往邻居中心聚）。讲师指出这类系统常常**不必写拉格朗日量**，直接从 $F=ma$ 汇总各邻居的力再数值求解即可，与广义粒子的写法等价。

- **质量-弹簧系统（mass-spring system）**：用弹簧连接粒子，可做布料（网格顶点是粒子、边是弹簧）、头发（发丝是折线加小弹簧）、蹦床。与角色互动需固定部分顶点并处理穿透。

- **显式与隐式（explicit vs implicit）**：显式给出"如何算出下一状态"，隐式只给出"下一状态必须满足的关系"。这个概念在几何部分出现过（隐式曲面 vs 参数曲面），这里再次用来区分前向欧拉与后向欧拉。

- **稳定性与数值阻尼（stability / numerical damping）**：稳定指模拟不会越算能量越大发散；数值阻尼指模拟"凭空多出摩擦"导致逐渐停摆。在交互式动画系统里，"保证不炸"往往比"精确"更重要。

- **一致性与收敛（consistency / convergence）、守恒与辛性（conservation / symplectic）**：随着 $\tau \to 0$，差分近似趋近真实导数即一致；数值方法长期保持能量或几何结构的性质，对天体、单摆这类长期模拟至关重要。

- **五种导数计算方法**：手动推导、数值微分（finite difference）、自动微分（automatic differentiation，与反向传播本质相同）、符号微分（symbolic differentiation，表达式树变换）、几何微分（geometric differentiation）。

## 关键公式 / 算法 / 数据结构

**牛顿第二定律与二阶形式**

$$m\ddot q = F(q,\dot q,t),\qquad \ddot q = \frac{F}{m}$$

双点表示二次时间导数。拆成两个一阶 ODE 才能进求解器：

$$\dot q = v,\qquad \dot v = \frac{F(q)}{m}$$

**标量指数型 ODE 的解析解**：$\dot u = au \Rightarrow u(t)=b\,e^{at}$；$a>0$ 指数爆炸，$a<0$ 指数衰减。讲师特别纠正了自己："不是 $a<1$ 就衰减，而是 $a<0$ 衰减。"

**抛石的解析解**（只受重力时）：

$$v(t)=v_0+t\frac{G}{m},\qquad q(t)=q_0+t\,v_0+\frac{t^2}{2}\frac{G}{m}$$

**拉格朗日流程**（以单摆为例，用 $\theta$ 作广义坐标）：

$$T=\tfrac12 m\ell^2\dot\theta^2,\quad V=mg\ell\cos\theta,\quad L=T-V$$

$$\frac{d}{dt}\frac{\partial L}{\partial \dot\theta}-\frac{\partial L}{\partial \theta}=0 \;\Rightarrow\; m\ell^2\ddot\theta=-mg\ell\sin\theta \;\Rightarrow\; \ddot\theta=-\frac{g}{\ell}\sin\theta$$

小角度 $\sin\theta\approx\theta$ 得简谐振子 $\ddot\theta=-\frac{g}{\ell}\theta$，解为 $\theta(t)=\cos\big(\sqrt{g/\ell}\;t\big)+b$ 形式；一般情形无闭合解。

**弹簧势能与力**：

$$U=\tfrac12 k(\ell-\ell_0)^2,\qquad \ell=\|x_1-x_2\|$$

$k$ 是刚度（stiffness），越大越难拉伸压缩——这也是"刚性系统（stiff system）"要小时间步长的根源。

**前向欧拉（forward / explicit Euler）**：

$$q_{k+1}=q_k+\tau f(q_k)$$

**后向欧拉（backward / implicit Euler）**：

$$q_{k+1}=q_k+\tau f(q_{k+1})$$

**稳定性分析（线性测试方程 $\dot u=-au$，$a>0$）**：
前向：$u_n=(1-\tau a)^n u_0$，需 $|1-\tau a|<1$，即 $\tau<2/a$；
后向：$u_{n+1}=\dfrac{1}{1+\tau a}u_n$，因 $1+\tau a>1$ 恒成立，**无条件稳定**，但每步都衰减，即数值阻尼。

**辛欧拉（symplectic / semi-implicit Euler）**：

```
v_{k+1} = v_k + τ · F(q_k)/m   // 用旧位置更新速度
q_{k+1} = q_k + τ · v_{k+1}    // 用新速度更新位置
```

速度与位置交错前进，单摆的能量几乎精确保守。

**数值微分与方向导数/梯度**：

$$f'(x_0)\approx\frac{f(x_0+h)-f(x_0)}{h},\qquad D_x f(q_0)=\lim_{\varepsilon\to0}\frac{f(q_0+\varepsilon x)-f(q_0)}{\varepsilon}$$

$$\langle \nabla f(q_0),\,x\rangle = D_x f(q_0)$$

梯度即势能的导数给出力；数值微分对每个坐标都要扰动一次，代价是 $O(n)$ 次函数求值，且 $h$ 太小会因浮点相消导致误差反而上升（经典的"U 形误差曲线"）。

**前向模式自动微分**（dual number $(f, f')$）：以 $f(x)=ax^2$ 在 $x=2$ 为例，从 $(2,1)$ 出发，乘法规则 $(u,u')(v,v')\to(uv,\ uv'+vu')$，得导数为 $4a$，与 $2ax|_{x=2}$ 一致，精度达浮点级。

**三角面积梯度的几何解**：面积 $=\tfrac12\|\mathbf e\|\,\|\mathbf h\|$，沿底边方向移动 $P$ 不改变面积，故梯度方向与底边垂直；再乘单位法向：

$$\nabla_P A = \tfrac12\,\hat n\times \mathbf e$$

比 Mathematica 输出的"一长串符号堆"简洁得多。

**可复用的数据结构/思想**：整体状态打包成一个长向量 $q$（广义坐标），求解器只负责"输入向量、输出新向量"。

## 讲解脉络

1. **回顾与动机**（开篇）：关键帧加样条太费工，切换视角到物理模拟；列出优缺点——省人力、但算力贵，且诞生于 15–20 年前才变得可行的硬件。

2. **运动学 vs 动力学**：借牛顿"运动的变化与施加的力成正比"引出区分，并让听众判断上一集的关键帧插值属于哪一类（答案是运动学）。

3. **状态观**：从 $F=ma$ 出发，引出构型 $q$、速度、质量/转动惯量、外力、约束 $g=0$；用台球桌把多物体状态压成一个 12 维向量，提出"轨迹是高维空间中的曲线"。

4. **ODE 与拉格朗日**：先讲最简标量 ODE 及其指数解，再把二阶牛顿方程拆为两个一阶 ODE；用抛石头的解析解说明"手算能做的事"，再用单摆说明"手算做不了"，于是引出拉格朗日量 $L=T-V$、欧拉-拉格朗日方程，完整推导出 $\ddot\theta=-\frac{g}{\ell}\sin\theta$。

5. **复杂性的涌现**：小角度近似得到简谐解，但原方程无闭合解；双摆演示混沌；三体/银河系模拟；鸟群与 Reynolds 模型；粒子系统与群体行为（人群疏散、流体、沙、爆米花、分子动力学、暗物质）；再到质量-弹簧（蹦床、布料、头发）。

6. **数值积分核心**：把导数换成差分，$q(t)\to q_k$，得到 $(q_{k+1}-q_k)/\tau=f(\cdot)$；关键问题只剩"在哪个时刻求值 $f$"。由此依次展开前向欧拉（不稳定、会越转越快）、后向欧拉（稳定但衰减）、辛欧拉（能量几乎守恒），并用线性测试方程给出定量分析。

7. **什么算"好"积分器**：稳定性、准确性、一致性/收敛、守恒/对称、效率，没有唯一最优解，必须按任务选工具。

8. **导数怎么算**：手动、数值、自动（前向模式为主，提及反向模式）、符号（表达式树、$\sin(z/x+5y)$ 的例子）、几何微分（三角面积梯度），并比较各自的精度、实现成本与通用性；最后预告接触与碰撞响应留待下次，然后转入优化。

## 重点结论

1. 基于物理的动画 = 写出运动方程 + 数值时间积分；省人力但费算力，适合生成复杂而丰富的涌现行为。
2. 一切系统都可以编码成一个广义坐标向量 $q$ 在高维空间中的一条曲线，这套观点让算法与维度、与具体系统无关。
3. 拉格朗日方法把"画受力图"变成"写动能减势能再做两次求导"，通用、少犯错、且直接对应欧拉-拉格朗日方程。
4. 前向欧拉虽然最直观（沿速度走一小步），但对刚性系统会注入能量：单摆会越摆越快直到高速旋转；线性分析给出 $\tau<2/a$ 的硬限制。
5. 后向欧拉需解隐式方程，无条件稳定，但会带来数值阻尼（单摆逐渐停下），缓解办法只能是减小 $\tau$——这又回到原先想避免的问题。
6. 辛欧拉用"先更新速度、再用新速度更新位置"的交错写法，实现几乎零成本，却几乎保持能量守恒，是实用首选之一。
7. 实时动画更看重"别炸"和"好看"，科学计算更看重精度与收敛；不同标准催生了众多积分器。
8. 数值微分的 $h$ 并非越小越好；自动微分精度高、速度快，但要把所有数值类型替换成 AD 类型；符号微分常生成臃肿表达式，对三维矢量和矩阵运算尤其不擅长，几何直觉推导往往能给出更简洁的结果。

## 字幕含糊或可能有误的地方

- **"石头 q 的二阶导数等于 g/m 乘以 f/m"**：应为 $\ddot q = G/m$（或 $F/m$，$F=G$ 是重力）。"g/m 乘以 f/m"是转写把两串公式叠在了一起。
- **"岩石必须位于单位圆上""必须保持单位法向量"**：单摆摆锤应约束在半径为 $\ell$ 的圆上（"单位"是把"长度 $\ell$"听成了"单位"）；"单位法向量"应是"长度/范数（norm）"被误识。
- **"我们只需说 q 的二阶导数等于 g/m"**：同上，应为力除以质量；讲师原文也说过"g/m 这个常数"，语义应为重力加速度 $g$（再除以 m）。
- **"q(t) 等于 q₀ 加上 t 乘 v₀ 加上 t²/2 乘 mg"**：末尾应是 $\frac{t^2}{2}\cdot\frac{G}{m}$（加速度），不是 $mg$。同理"$v = v_0 + t\cdot g/m$"。
- **"势能 $V=mg\ell\cos\theta$"的符号与参考点**：$V=mg\ell\cos\theta$ 是以圆心为高度零点（悬点向下为正）的写法；若以悬点为原点、向下为正，常见写法是 $-mg\ell\cos\theta$。但按讲师得到的 $\ddot\theta=-\frac{g}{\ell}\sin\theta$（稳定平衡在 $\theta=0$），$V=mg\ell\cos\theta$ 恰好自洽，因此不是错误，只是参考点反了，容易让听众困惑。
- **"拉格朗日量里两项都含质量，可以提取公因式并乘以二分之一长度平方 θ 点平方加 g 乘 l 乘 cosθ"**：口述对简化的描述混乱，$L$ 应整理为 $\frac12 m\ell^2\dot\theta^2 + mg\ell\cos\theta$ 型；"glcosθ 项的导数是负正弦"则对应 $mg\ell\cos\theta$。整体推导结论正确，过程转写有噪声。
- **"$a$ 小于 1 就衰减，大于 1 就爆炸"**：讲师自己当场纠正为"$a<0$ 衰减，$a>0$ 爆炸"，字幕保留了前后矛盾，需以纠正后的为准。
- **前向欧拉稳定性条件**："只有 $|1-\tau a|<1$……特别是要确保 $\tau<2/a$"——转写里"1−τ的绝对值"是"$|1-\tau a|$"的误识。
- **后向欧拉步长因子**："$U_{n+1}=1/(1+\tau a)U_k$……只要 $1$ 加上 $\tau$，这个系统就会持续衰减 $a$ 的值大于 1"：应为 $1+\tau a$ 恒大于 1，因此无条件稳定。字幕断句严重错乱。
- **后向欧拉"无条件稳定"与"辛欧拉"**：辛欧拉部分口述"从当前速度更新到下一速度使用当前状态的数据"，应理解为"用当前位置/旧状态更新速度"，之后再用新速度更新位置。
- **"符号微分……可以多次为新值评估，与前向模式对比自动微分可能需要重复相同计算多次"**：逻辑跳跃，本意是符号微分一次求导后可对任意新输入重复求值；前向模式对每个输入变量都要重算一遍（反向模式则一次算出全部梯度）。
- **"前向模式自动微分"的数值展示**："$f(x)=ax^2$，$x=2$ 时值 4a、导数 4a"——两者巧合相等（$4a=2ax$ 在 $x=2$ 时），讲师特意点明了这一点，转写中也出现了"恰好也是 4a"的残句。
- **"巴恩斯-胡特算法"**：应为 Barnes–Hut；"快速多极子"即 FMM（fast multipole method），转写基本可辨。
- **"分子动力学 / 融化冰晶 / 晃动的声音来自动能"**一句语义断裂，应是"分子振动对应动能，颜色来自电磁场振动"这类讲解的拼接；"没有闭合表达式"处字幕"闭合解/闭合表达式"混用。
- 大量"好的""嗯""对吧"以及"实际上发生的是"重复，是语音填充，不影响语义。
