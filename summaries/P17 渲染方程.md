# P17 渲染方程

## 一句话概括

本集把前面几讲讲过的 radiance（辐射度）、辐照度、方向和半球积分等概念收拢成一个统一的**渲染方程**（Rendering Equation），指出它的求解难点是**递归**，然后用反射项（BRDF）、镜面/漫反射/折射等具体散射模型把方程“填实”，最后用蒙特卡洛采样加递归光线追踪（即路径追踪 pathway tracing 的雏形）给出一个求解框架。

## 本集主题与目标

本集的目标只有一个：回答“**如何利用前面关于颜色与光的测量的知识，生成逼真的图像**”。讲师先做快速回顾，重建入射/出射辐射度与辐照度的概念基础；再正式推出渲染方程，说明发光项、散射项（BRDF）、余弦项三部分各自的含义；接着花大量篇幅讨论散射函数到底有多复杂——从理想镜面、朗伯漫反射、光泽反射、逆向反射，到折射、菲涅耳式随角度变化的反射率、各向异性，再到次表面散射（BSSRDF）；最后回到“怎么算”，给出蒙特卡洛估计 + 递归光线追踪的伪代码，并引向路径追踪算法。为下一讲蒙特卡洛积分做铺垫是本集收尾处明确宣布的目标。

## 核心概念

- **Radiance（辐射度）与入射/出射辐射度**：radiance 是单位时间、单位立体角、单位投影面积上的辐射能量，它“捕捉了场景中所有光线的信息”。讲师强调入射辐射度 $L_i$ 与出射辐射度 $L_o$ 不是两个物理量，而只是同一物理量在不同场合的引用方式：$L_i$ 是我在街角抬头看天空和楼群时每个方向射来的光，$L_o$ 是光源朝不同方向发出的光。之所以重要，是因为图像生成本质上就是求某点某方向的出射 radiance，而 radiance 对**方向**高度敏感。
- **Irradiance（辐照度）**：radiance 在各个方向上的积分。讲师明确说“辐照度 e 始终是 radiance 的积分”，例如仰望天空时总入射光就是对上半球 $H^2$ 积分 $L(\omega)\cos\theta\,d\omega$。它重要在于它是渲染方程中“把某个方向的入射光累加成该方向总量的那一步”的中间量，也是后面反照率归一化的分母。
- **渲染方程（Rendering Equation）**：出射 radiance 等于该点的**自发光**加上所有入射方向 radiance 的半球积分，积分里乘上 r余弦项和和散射函数 $f_r$。成功渲染器（photorealistic renderer）的核心工作就是估计这个量。
- **递归性**：方程右边需要 $L_i$，而 $L_i$ 本身又满足同一个方程，只是位置换成了光线击中的下一点。估计 radiance 因此变成“递归求解渲染方程”；递归的终止条件/基例是**击中发光体**（如灯泡）。
- **Scattering / 散射函数 $f_r$（BRDF，Bidirectional Reflectance Distribution Function，双向反射分布函数）**：描述入射方向 $\omega_i$ 的光被反射到出射方向 $\omega_o$ 的比例,决定表面外观——吸收哪些波长、在哪些方向强烈反射。BRDF 是渲染方程里“最复杂”的小函数，也是本集后半段的主题。
- **镜面反射（specular reflection）**：光线以唯一确定的方向反射，即完美镜子。用角度描述时 $\theta_o = \theta_i$，绕法线的方位角相反（$\phi_o = -\phi_i$）；用向量描述时 $\omega_o = -\omega_i + 2(\omega_i \cdot n)n$。其 BRDF 含 Dirac $\delta$（狄拉克 $\delta$ 函数），严格说不是函数而是分布（distribution），因此不能靠“随机发一条光线看有多少光过来”的方式来采样。
- **漫反射（diffuse reflection）**：出射方向与入射方向无关，光在所有方向均匀散射，如墙漆、陶土花盆。此时 $f_r$ 是常数，可以提出积分号外，剩下的积分正是辐照度。
- **Albedo（反照率）**：归一化后的漫反射系数，记作 $\rho$（0 到 1 之间），反映吸收或散射的程度；均匀漫反射的 BRDF 写作 $f_r=\rho/\pi$，$\pi$ 来自半球积分的归一化。
- **中间材质**：光泽镜面（glossy，在镜面方向附近向多个方向散射，塑料的“轻微光泽”）、逆向反射（retroreflection，自行车后反光器、月球看起来不像明暗分明的球体）都说明真实材料大多介于理想镜面与理想漫反射之间。
- **能量守恒**：对每对入射/出射方向，$f_r \ge 0$，且在整个半球积分后**不超过 1**。不到 1 的部分被吸收转化为热能（夏天车里的黑色皮座椅被晒热），所以不应该等于 1。
- **Helmholtz 互易性（reciprocity，亥姆霍兹互易性）**：从 $\omega_i$ 入射散射到 $\omega_o$ 的量，等于从 $\omega_o$ 入射散射到 $\omega_i$ 的量。直观解释是微观上材料由许多“小镜子”构成。
- **折射与斯涅尔定律（Snell's law）**：光穿过表面进入另一种介质时方向偏折，由入射介质与透射介质的折射率 $n_i$、$n_t$ 决定。讲师还讲了**全内反射**：从光密介质（如水）射向光疏介质（如空气）时，入射角足够大就不再透射,而像镜面一样反射；在海中抬头看到的锥形亮区和外面的暗区就是这个现象。
- **各向异性（anisotropy）反射**：反射率依赖方位角 $\phi$，在抛光金属（门把手、茶壶）上很明显；实现时需要确定各向异性方向，通常烘焙进纹理。
- **次表面散射（subsurface scattering）与 BSSRDF（Bidirectional Subsurface Scattering Reflectance Distribution Function）**：光线在某点入射、在材料内部漫反射后从**另一点**射出，如薄玉雕塑、被背后光照亮的耳朵呈红色、树叶的半透明。这违背了 BRDF“同点入射同点射出”的假设，需要把函数从 $f_r(\omega_i,\omega_o)$ 扩展为 $S(x_i,\omega_i,x_o,\omega_o)$，散射项也从半球积分变成“整个半球 × 整个表面”的多重积分，代价极高但效果显著（大理石雕像的例子）。

## 关键公式 / 算法 / 数据结构

渲染方程：

$$L_o(p,\omega_o)=L_e(p,\omega_o)+\int_{H^2} f_r(p,\omega_i,\omega_o)\,L_i(p,\omega_i)\,(\omega_i\cdot n)\,d\omega_i$$

其中 $L_e$ 为发光项，$f_r$ 为散射函数（BRDF），$(\omega_i\cdot n)$ 为入射方向与法线的夹角余弦。

辐照度与半球积分：

$$E(p)=\int_{H^2}L(\omega)\,(\omega\cdot n)\,d\omega$$

球面积分的参数化写法（余弦项的来源之一）：

$$\int_{S^2} f\, d\omega=\int_\varphi\int_\theta f(\theta,\varphi)\cos\theta\,d\theta\,d\varphi$$

均匀漫反射 BRDF：

$$f_r=\frac{\rho}{\pi},\qquad L_o=\frac{\rho}{\pi}\int_{H^2}L_i(\omega_i)\cos\theta_i\,d\omega_i=\frac{\rho}{\pi}E$$

镜面反射方向：

$$\omega_o=-\omega_i+2(\omega_i\cdot n)\,n,\qquad \theta_o=\theta_i,\quad \phi_o=-\phi_i$$

镜面 BRDF 用 $\delta$ 函数表达（字幕只说“涉及狄拉克 δ 的函数”，未给出全部常数）。

斯涅尔定律（字幕读作 “Ada i / Ada t”，应为 $n_i,n_t$）：

$$n_i\sin\theta_i=n_t\sin\theta_t,\qquad \phi_t=\phi_i$$

蒙特卡洛估计（字幕给出的估计式）：

$$\hat L_o\approx\frac1n\sum_{j=1}^{n}\frac{f_r(\omega_j,\omega_o)\,L_i(\omega_j)\,(\omega_j\cdot n)}{p(\omega_j)}$$

伪代码（按字幕描述的算法结构重写）：

```
render(p, n, wo):            # 已知击中点 p、法线 n、出射方向
    Lr = 0
    repeat n times:
        wi = random direction sampled from p(wi)   # 例如半球均匀采样
        hit = trace_ray(p, wi)                     # 向入射方向反向追踪
        Li = render(hit.p, hit.n, -wi)             # 递归：同一个子程序
        Lr += fr(wi, wo) * Li * dot(wi, n) / p(wi)
    return Lr / n
```

路径追踪（path tracing）思路（本集只讲框架）：
- 把渲染方程拆成**直接光照**（光线直达表面）与**间接光照**（多次反弹后到达），各自用蒙特卡洛采样估计，每像素采几百个样本让误差平均掉。
- 递归永不终止的问题用**截断**处理，仍然可以得到“平均正确”的图像。
- 方差降低手段：让采样概率分布匹配散射函数的形状，使高散射区域采更多样本。

## 讲解脉络

1. **回顾**：先重申 radiance 是描述场景光线信息最完整的量，再区分入射/出射 radiance 只是引用方式、强调其方向依赖性，然后区分 radiance 与辐照度（辐照度是积分）。
2. **澄清余弦混淆**：讲师专门停下来讲“余弦出现在两个完全不同的地方”——朗伯余弦定律（倾斜材料时能量摊到更大面积）与球面积分参数化的 $\cos\theta$，避免学生把两者搞混。这是典型的“先把符号讲清楚再上方程”的推进。
3. **推出渲染方程**：写出 $L_o = L_e + \int f_r L_i \cos\theta$，逐个解释三项，然后点出最难的是**递归**：右边要的 $L_i$ 又是一个同样的方程实例；递归的基例是击中发光体。
4. **为什么必须光线追踪**：因为方程难求，必须递归；光栅化控制力有限，无法自然表达“评估哪条光线”。于是引出从相机向场景反向追踪（虽然直觉上想从光源打粒子到相机，但终点是已知的像素，反向追踪更合理）。
5. **深挖散射项**：从镜面、漫反射、光泽、逆向反射依次展示同一茶壶上不同 BRDF 的效果；再讲能量守恒（为何是 ≤1）、亥姆霍兹互易性、单位分析（$f_r$ 的量纲是每弧度倒数）、朗伯反射的积分推出 albedo。
6. **镜面与透射**：镜面用角度和向量两种写法表达；镜面 BRDF 用 $\delta$ 分布，说明它要特殊对待；然后进入折射、斯涅尔定律、全内反射、随视角增大的反射率，以及各向异性。
7. **超出 BRDF 的现象**：次表面散射引出 BSSRDF 和四参量函数 $S$，指出计算量爆炸但效果值得。
8. **怎么算**：抛开 $L_e$ 只看反射项，给出蒙特卡洛估计式与递归伪代码，再过渡到把方程拆成直接/间接光的路径追踪，并用两个球体的对比图展示加入间接光后“更像照片”。

这样推进的逻辑是：**先定义问题（方程）→ 说明问题为何困难（递归）→ 说明难在哪一项（散射）→ 回到算法（采样 + 递归）**，由直觉到数学，再回到实现。

## 重点结论

- 逼真渲染的核心任务就是估计渲染方程，而渲染方程的难点在于递归：$L_i$ 由同一方程给出，只是换地点。
- 递归的基例是**击中自发光物体**，这是方程能够终止的物理依据。
- 光栅化快，但无法自然表达这种全局、递归的光传输，所以需要光线追踪类的算法。
- $\cos\theta$ 在渲染中出现在两个独立来源：物理上的朗伯余弦定律和球面积分的参数化，学生最易混淆。
- BRDF 满足非负、半球积分不超过 1（吸收转热能）与亥姆霍兹互易性；均匀漫反射时 $f_r=\rho/\pi$。
- 镜面反射的 BRDF 是分布而非函数，采样与积分都需要特殊处理。
- BRDF 假设“同点进出”不足以描述真实材质，BSSRDF 把积分搬到整个表面上，代价高但真实感提升明显。
- 求解路线：蒙特卡洛随机采样估算半球积分，除以概率密度、递归追踪入射方向，再用分解（直接光 + 间接光）与路径截断控制成本与方差。
- 间接光对真实感至关重要，缺少它画面会显得太暗、太“合成”。

## 字幕含糊或可能有误的地方

- “余弦的出现源于物理原因即朗伯余弦定律……另一个余弦来自球面积分的写法”一句表达绕，字幕把“投影面积里的余弦”和“朗伯定律的余弦”当成两个；“朗伯余弦定律”这个叫法在原文里口语化，判断是讲课件时的简写。
- “r余弦”一段的断句错乱（“我们想要计算出射辐射度……右边计算入射辐射度，控制入射辐射度的方程是什么”），实际是自问自答的修辞，应理解为“右边需要的 $L_i$ 由同一方程控制”。
- 斯涅尔定律中的符号被识别成 “Ada i / Ada t”，结合上下文应为 $n_i$（入射介质折射率）与 $n_t$（透射介质折射率）；“底部有这个方程”属于指屏幕的动作，字幕没有公式本身。
- “欧米伽零”“ω 零”与“ω_o（omega o）”交替出现，“欧米伽 i / ω 一”等写法混用，应统一为 $\omega_i$、$\omega_o$；同段落写“出是等于负v”是 $\phi_o=-\phi_i$ 的识别噪声。
- “亥姆霍兹互易性”的英文应为 reciprocity，字幕出现“具有对称性”和“亥姆霍兹互易性”两种说法，指的是同一性质。
- “反照率”段落中“这个亮度因子有一个通用名称即反照率”表述不严谨：albedo 是 $f_r=\rho/\pi$ 里的 $\rho$，不是亮度因子；讲师意思是该常数即反照率。
- 能量守恒段落说“整个半球范围内积分不超过一”，严格说是 $\int f_r\cos\theta\,d\omega\le 1$，字幕漏了余弦项，属于口播简化。
- 次表面散射段落中“双向次表面反射分布函数”“BSS RDF”“BRRDF”“BRDF 的扩展”多种读法混用，应统一 BSSRDF；四参量的输入点/出射点符号 $x_i$、$x_o$ 也不能完全确定是讲师原样还是转写误差。
- “路径追踪算法”（path tracing）被称作“将使用的首个算法”，同时文中还有一句“这引导我们想到路径追踪算法”，疑为原话重复。
- 伪代码段“出射方向的辐亮度 W r 即为光线方向的反方向”“保持一个累积总和 l 下标 r”有识别错误，应为 $L_o$（出射 radiance）与累加变量，“W”疑为 $L$ 的误识别。
- “Ada t”之外，“Thitm” “θ的余弦相同”重复两遍，属于口播重复。
