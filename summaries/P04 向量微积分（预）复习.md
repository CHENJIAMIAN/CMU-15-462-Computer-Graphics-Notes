# P04 向量微积分（预）复习

## 一句话概括

把向量、范数、内积、叉积、行列式重新当作几何量，再搭起梯度、散度、旋度、拉普拉斯与 Hessian 这套工具，说明它们为何是图形学描述变化率、做优化与模拟的通用语言。

## 本集主题与目标

这是开学数学复习第二讲，接上一集线性代数，主题是 vector calculus（向量微积分）。动机很直接：现代图形学大量建立在偏微分方程上，散度、旋度、拉普拉斯支撑着物理动画、几何处理与图像处理，凡要对向量值量做微分或优化都需要这套工具。

目标分两层：表层是补齐范数、内积、叉积、行列式、梯度、散度、旋度、拉普拉斯、Hessian 这些工具并给出坐标公式；深层是换视角——上一集把向量当抽象代数对象，这一集要求把它当成空间里看得见的几何实体，先问"几何上是什么意思"，再问"坐标里怎么写"。

## 核心概念

**Euclidean norm（欧几里得范数）**：衡量向量总长度。特殊之处是在刚体运动（旋转、平移、反射）下不变，故不依赖坐标系；坐标式 $\sqrt{\sum u_i^2}$ 只在正交基下等于几何长度。

**Inner product（内积）与 dot product（点积）**：内积衡量对齐程度，几何定义 $\|u\|\|v\|\cos\theta$ 与坐标无关；坐标式 $\sum u_iv_i$ 是点积，只在标准正交基下才等于内积。图形学常用非正交基表示函数或信号，此时直接点积是错的，要引入 mass matrix（质量矩阵）修正。

**Cross product（叉积）**：模长等于两向量张成的平行四边形面积，方向垂直于该平面。它只在三维唯一：二维找不到法向，四维法向又太多；二维中人们把它当有符号面积用。

**Determinant（行列式）**：几何上是有符号体积。三向量为列的三阶矩阵，行列式就是以它们为棱的平行六面体体积，符号编码右手系还是左手系；矩阵编码线性映射时，它是体积缩放倍率，符号表示定向是否翻转。

**Gradient（梯度）**：把所有方向的方向导数打包成一个向量，指向最速上升方向。更本质的定义是 $\nabla f$ 为唯一满足 $\langle\nabla f,u\rangle=D_uf$ 的向量——这里已隐含内积的选择。

**Divergence / Curl（散度 / 旋度）**：散度作用于向量场输出标量，衡量源与汇、扩张与收缩；旋度衡量局部旋转的强度与轴向，二维退化为标量。

**Laplacian（拉普拉斯算子）**：标量到标量的线性算子，等于梯度的散度，也等于各坐标二阶偏导之和。它刻画局部曲率，是热传导、波动、流体建模的基础；推广到曲面即 Laplace–Beltrami 算子，可用于形状检索。

**Hessian（海森矩阵）**：二阶偏导排成的对称矩阵，可理解为"梯度的导数"，给出函数的最佳二次近似，是快速收敛优化算法的核心。

## 关键公式 / 算法 / 数据结构

- 内积：$\langle u,v\rangle=\|u\|\|v\|\cos\theta$；仅标准正交基下 $u\cdot v=\sum_i u_iv_i$
- 叉积：$\|u\times v\|=\|u\|\|v\|\sin\theta$；$(u\times v)_1=u_2v_3-u_3v_2$，其余循环置换
- 叉积即 90° 旋转：$n\times(n\times u)=-u$
- 矩阵形式：$u^{\mathsf T}v$、$u^{\mathsf T}Av$（$A$ 对称）、$u\times v=[u]_\times v$（$[u]_\times$ 反对称）
- 三重积：$u\cdot(v\times w)=\det[u,v,w]$，循环置换不变、交换变号
- Lagrange 恒等式：$u\times(v\times w)=v(u\cdot w)-w(u\cdot v)$
- 方向导数：$D_uf=\lim_{\varepsilon\to0}\frac{f(x+\varepsilon u)-f(x)}{\varepsilon}$
- 二阶泰勒：$f(x)\approx f(x_0)+\nabla f^{\mathsf T}(x-x_0)+\tfrac12(x-x_0)^{\mathsf T}H(x-x_0)$
- 求导：$\nabla_u(u^{\mathsf T}v)=v$，$\nabla_x(x^{\mathsf T}x)=2x$，$\nabla_f\langle f,g\rangle=g$，$\nabla_f\|f\|^2=2f$
- 散度 $\nabla\cdot x=\sum_i\partial x_i/\partial x_i$；二维旋度 $\partial x_2/\partial x_1-\partial x_1/\partial x_2$
- 拉普拉斯 $\Delta f=\nabla\cdot\nabla f=\sum_i\partial^2f/\partial x_i^2$；网格上约为"邻居平均减自身"
- Hessian：$H_{ij}=\partial^2f/\partial x_i\partial x_j$，且 $H=H^{\mathsf T}$

## 讲解脉络

**一、动机。** 回顾上集，推荐 3Blue1Brown 与 Robert Ghrist 的课程，请学生在 Piazza 分享资源，点明图形学由 PDE 驱动，需要变化率的语言。

**二、把线性代数几何化。** 从范数的刚体运动不变性讲起，再讲内积的几何定义与坐标点积的差别，警告非正交基下公式失效。接着讲叉积的面积/垂直刻画，追问"为什么只有三维有叉积"，比较右手定则与行列式定义，给出"叉积即平面内 90° 旋转"的技巧。

**三、矩阵表示与行列式。** 先示范 $u^{\mathsf T}v$、$u^{\mathsf T}Av$、反对称矩阵三种写法；再转行列式，先吐槽余子式展开"没头没脑"，再用平行六面体讲通：$u\cdot(v\times w)$ 就是底面积乘高，三种循环写法同体积，交换变号。由此引出线性映射行列式即体积缩放率。

**四、从一元导数到梯度。** 回到差商极限，讨论左右导数不一致导致不可导，强调图形学中很多有趣函数恰恰不可导；再把导数解释为最佳线性近似，铺开泰勒级数。升级到多元时先定义方向导数（沿方向切片），再说所有方向导数可压缩成一个向量，于是得到梯度，并给三种理解：偏导列表、最速上升、内积恒等式。

**五、对矩阵和函数求导。** 用 $\nabla_u(u^{\mathsf T}v)=v$、$\nabla_x(x^{\mathsf T}x)=2x$ 说明矩阵求导与普通求导同构；再把套路推到泛函，用 $\varepsilon$ 展开验证 $\nabla_f\|f\|^2=2f$，指出这是泛函分析与变分法的起点。

**六、向量场与三大算子。** 梯度场是第一个向量场例子。散度讲源汇，旋度讲涡旋，各配 $\cos,\sin$ 的例子算到底，并指出示例中"旋转 90° 后的场的散度等于原场的旋度"。随后用流体模拟论文的对比图说明：把求解变量从速度场换成流函数 $\psi$，效果天差地别。

**七、拉普拉斯与 Hessian。** 拉普拉斯定位为"二阶导数的多元版"，给出三种等价写法与网格离散直觉；Hessian 则是二阶泰勒的二次项系数矩阵，对称，是优化算法的核心。最后宣布数学复习结束，下次讲 rasterization（光栅化）。

## 重点结论

1. 几何定义与坐标公式不能混用：$\sqrt{\sum u_i^2}$、$\sum u_iv_i$ 只在正交基下成立。
2. 叉积是三维特有运算，模长是面积，方向由定向约定；行列式定义比右手定则更精确、更好写代码。
3. 行列式是有符号体积，线性映射的行列式是体积缩放率；三重积是理解这一切的钥匙。
4. 梯度的真正定义是"与任意方向内积给出该方向导数"的唯一向量，可推广到函数空间。
5. 散度刻画源汇、旋度刻画旋转，二者经 90° 旋转相互转化，是流体速度场分解的基础。
6. 拉普拉斯 = 梯度的散度 = 二阶偏导和，既是曲率，也是与邻域平均的偏差，还是 Dirichlet 能量的梯度。
7. Hessian 是梯度的导数、最佳二次近似，对称性来自混合偏导可交换。
8. 方法论：遇到陌生对象求导，先回极限定义、再回分量展开；推清楚后就丢掉坐标，直接用算子恒等式运算。

## 字幕含糊或可能有误的地方

- **"三蓝学院" / "One Brown"**：应为 **3Blue1Brown**，音译失真。
- **"Robert Gryce"**：应为 **Robert Ghrist**（宾大），拼写失真。
- **"naba" / "naba平方"**：应为 **nabla**（$\nabla$）与 $\nabla^2$。
- **"德雷能能量"**：应为 **Dirichlet energy**（狄利克雷能量），即 $\int\|\nabla f\|^2$。
- **"黑塞矩阵"与"海森矩阵"混用**：同一集两种译名交替，都指 Hessian。
- **"一范数梯度平方"**：应为"梯度的 $L^2$ 范数平方"，是口误或转写错误。
- **叉积行列式定义处混乱**：字幕说"行列式的平方根……使行列式为正取平方根"。准确说法是 $\det[u,v,u\times v]=\|u\times v\|^2$，开正平方根得 $\|u\times v\|=\|u\|\|v\|\sin\theta$，字幕把平方与开方的顺序讲乱了。
- **拉普拉斯凹凸描述断裂**：字幕"山顶为负……拉普拉斯是正的"中间插话，但结论对——山顶 $\Delta f<0$，山谷 $\Delta f>0$。
- **旋度/散度示例指代不清**：讲二维旋度时把 $x=(-\sin v,\cos u)$ 与散度示例 $x=(\cos u,\sin v)$ 并置，口述"这个函数熟悉吗"缺少指代；实际是同一场旋转 90° 的版本，两者算出的标量恰好都是 $-\sin u+\cos v$。
- **"三条高线交于同一点"**：讲 Jacobi 恒等式的几何解释时只是类比提示，字幕未展开，不宜当严格证明。
- **"矩阵手册"**：应指 **The Matrix Cookbook**，字幕只给中文意译。
