# P20 方差缩减

## 一句话概括

本集是「基于物理渲染」的收官讲座：先补齐蒙特卡洛积分（Monte Carlo integration）的概率论基础与估计量的「一致性 / 无偏性」判据，再用点光源照镜子、迪斯科球、门缝房间等失效场景说明朴素路径追踪（path tracing）为何方差巨大，最后系统梳理重要性采样（importance sampling）、路径空间视角、双向路径追踪（BDPT）、Metropolis 光线传输（MLT）、多重重要性采样（MIS）、分层采样、低差异序列、蓝噪声与别名表等一整套方差缩减手段。

## 本集主题与目标

渲染方程是递归积分方程，无法解析求解，只能诉诸数值积分，因此「采样策略」直接决定图像质量。本集目标是把方差从「只能靠堆算力」变成「能靠聪明地选样本」来压制。讲师强调这些技术不止属于图形学——蒙特卡洛积分被列为二十世纪十大算法之一，任何需要估计复杂积分的地方都用得上。

## 核心概念

- **蒙特卡洛积分**：在域 $\Omega$ 上随机取样本 $X_i$，对 $f$ 求值、平均、再乘域的体积。只要 $f$ 可积就成立，样本越多越接近真值。
- **期望与方差**：期望是「按概率加权的平均值」，方差是「偏离均值的平方的期望」，标准差是其开方。渲染时每像素独立估计，估计量的方差直接表现为噪点——方差决定噪声，噪声决定采样预算。
- **平均值的缺陷**：讲师用「在讲座中入睡的时间」举例：概率密度峰值在开头，平均入睡时间却是 44.9 分钟、波动约 $\pm15.8$ 分钟，只看均值会丢掉分布形状。
- **无偏（unbiased）与一致（consistent）**：无偏指估计量的期望等于真值（任意样本数都成立）；一致指样本数趋于无穷时，估计偏离真值的概率趋于零。二者互不蕴含，最易混淆。
- **重要性采样**：把均匀分布换成与被积函数形状相近的 $p$，每个样本同时除以概率密度。采得多的地方权重小、采得少的地方权重大，彼此配平。
- **路径空间（path space）积分**：把渲染看成在「所有可能的完整光路」上积分，每条光路是从光源到眼睛的路径，$f$ 是该路径携带的光通量。这提供了全局而非局部的重要性采样视角。
- **Metropolis 光线传输（MCMC）**：用依赖样本的随机游走替代独立采样，乐于停留在函数值高的区域，把「寻找稀有重要路径」变成「局部扰动优良路径」。
- **多重重要性采样（MIS）**：按平衡启发式（balance heuristic）加权结合多个采样策略，避免糟糕策略拖坏结果。
- **分层采样（stratified sampling）**：把域切成 $n$ 格、每格取一个样本，消除聚集与大空洞；方差永不劣于纯均匀采样。
- **差异（discrepancy）**：衡量样本与理想分布的偏离——任意区域内样本占比是否与该区域面积成正比。低差异样本使准蒙特卡洛（QMC）误差有界。
- **蓝噪声（blue noise）**：频谱上无方向偏好、无频率偏好、低频功率低的采样模式，模仿恒河猴视网膜感光细胞分布，抗混叠最好。
- **别名表（alias table）**：把任意离散分布改造成每列只有两个候选、比例固定的表，实现 $O(1)$ 采样（CDF 反演是 $O(\log n)$）。

## 关键公式 / 算法 / 数据结构

蒙特卡洛估计：

$$I=\int_\Omega f(x)\,dx \approx \frac{V}{N}\sum_{i=1}^N f(X_i)$$

重要性采样估计：

$$I \approx \frac{1}{N}\sum_{i=1}^N \frac{f(X_i)}{p(X_i)}$$

若 $p\propto f$，比例常数恰为 $1/I$，一个样本即得精确解——这就是「完美重要性采样」。但它需要先知道积分值（鸡生蛋问题），只能用来指导「让 $p$ 尽量贴近 $f$」。

棋盘格示例：$f(x,y)=1$（$\lfloor x\rfloor+\lfloor y\rfloor$ 为偶数）否则 $0$，黑白各半，期望 $=1/2$，方差 $=\frac12(0-\frac12)^2+\frac12(1-\frac12)^2=\frac14$。

二维路径空间：任何路径都由一串 0 到 1 的随机数决定，$k$ 维路径对应单位超立方体中的一点；把「两次反射」的两个角度 $(\theta_1,\theta_2)$ 画成二维图，击中白窗的路径亮、击中黑墙的暗，渲染就变成求这张图的总亮度。

Metropolis-Hastings 转移：$\alpha=f(\text{新})/f(\text{旧})$；若 $\alpha<1$ 以概率 $\alpha$ 接受，否则留在原地（$\alpha>1$ 时必然接受）。

平衡启发式 MIS：

$$\sum_{i=1}^{n}\frac{1}{N_i}\sum_{j=1}^{N_i}\frac{f(x_{ij})}{\sum_{k}p_k(x_{ij})}$$

差异定义：$\displaystyle D(X)=\max_{S}\left|\frac{A(S)}{A}-\frac{\#\{X\in S\}}{N}\right|$。

Koksma–Hlawka 不等式：$|I-\hat I|\le D(X^{*})\cdot V(f)$，误差被样本差异与被积函数全变差的乘积界住。

反转根函数（radical inverse）与低差异序列：

```
radicalInverse(1234, 10) = 0.4321   // 写成 r 进制后镜像到小数点后

Halton    : x_i = (radicalInverse(i,2), radicalInverse(i,3), radicalInverse(i,5), ...)
Hammersley: x_i = (i/n, radicalInverse(i,3), radicalInverse(i,5), ...)
```

Hammersley 更均匀，但必须预先确定样本总数 $n$，而渲染是不断加样本的渐进过程，这是它的主要局限。

别名表：遍历概率列表，把高于平均值的事件截断、超出部分补给低于平均值的事件，直到每列至多两个标签；采样时均匀选一列，再按该列存储的比例做一次「有偏硬币」决定返回哪个标签。

## 讲解脉络

1. **回顾与概率论铺垫**：从上次的蒙特卡洛光线追踪与渲染方程出发，说明为何要深入数值积分；补讲随机变量的期望与方差，用「恰在某时刻入睡的概率为零」建立密度函数的直觉。
2. **设定核心区分**：棋盘格例子算出期望 $1/2$、方差 $1/4$，随即点题——不能降低被积函数的方差，只能降低估计量的方差。
3. **一致性与无偏性**：用「网格黎曼和」「单点采样」两个估计量对照，讲清两者区别，并给出渲染算法对照表：光栅化（既不一致也有偏，但极快）、路径追踪（几乎无偏一致）、光子映射（一致但有偏）、辐射度（既不一致也有偏）。
4. **路径追踪为何失效**：镜子下的焦散需要「反射方向 → 点光源」这种零测度路径；迪斯科球场景中每次反弹后可见亮区只占极小立体角，长路径不断「乘」上这个极小概率。逐像素 16 → 128 → 8192 样本的实验说明堆算力解决不了。
5. **重要性采样与路径空间**：先讲局部重要性采样（按 BSDF 采样、按光源采样，两个极限是完美镜面只采反射方向、点光源直接连光），再切到「整条路径作为积分域」的全局视角，用超立方体可视化路径空间结构。
6. **全局策略**：BDPT 连接光源子路径与眼睛子路径；但门缝房间说明连 BDPT 也难找到窄缝路径，于是引入 Metropolis 随机游走（含遍历性与预热偏置问题），并用匹兹堡市中心图像演示「只往更亮处走」的自然涌现。
7. **组合与样本放置**：MIS 自动融合多策略；随后转向「如何生成样本点」——分层采样、低差异序列、蓝噪声与频谱分析、泊松圆盘、Voronoi/Lloyd 松弛，以及从大分布采样的别名表。最后回到渲染算法全景与「渲染器能否被形式化验证」的哲思收尾。

## 重点结论

- **要减的是估计量的方差，不是被积函数的方差**。函数给定、积分只有一个真值，可自由选择的只有采样与加权方式。
- **一致性与无偏性彼此独立**：「平均正确」不等于「最终正确」，反之亦然；误差是否可预测直接影响采样预算规划。
- **纯随机追踪遇上点光源加镜面，命中概率几乎为零**，这是路径追踪偏差与噪点的根源；迪斯科球这类「窄光源 + 高光材质」病态却常见。- **$p\propto f$ 时重要性采样最优**，单样本即可精确，但实践中只能追求形状接近。
- **MCMC 不必事先知道好路径在哪**，靠局部扰动在路径空间爬山；代价是必须处理遍历性（会漏掉函数值为零的区域）与预热偏置。
- **分层采样方差永不劣于均匀采样**，可由期望的线性性证明；蓝噪声各向同性、无频率偏好，是随机与低差异之间的好折中；低差异序列的误差界由差异 × 全变差决定。
- **性能权衡**：CDF 二分查找采样 $O(\log n)$，别名表 $O(1)$，在大环境贴图上差距巨大；Lloyd 松弛预计算贵，但样本模式可复用、摊销后很划算。
- **难以形式化保证正确**：只要把门缝缩小、把灯调亮，任何「已验证」的渲染器都能被构造出反例。

## 字幕含糊或可能有误的地方

- **「反根函数」**：应为 radical inverse，通译「反转根 / 基数反转」，译名不准。
- **「柯尔莫哥洛夫定理」**：实为 **Koksma–Hlawka 不等式**，与柯尔莫哥洛夫无关，属人名误认。
- **「这样它就既一致又无偏」与前文「不一致但有偏的」**：否定词被吞，指代错乱；应理解为网格估计「m 固定时有偏且不收敛，m→∞ 才一致」，单点采样「不一致但无偏」。
- **「什么种类的豌豆」**：应为「概率分布（PDF）」的误听，原句是「渲染中能用什么类型的概率分布」；同段「哈利」只是口头感叹。
- **「至少是各向异性的」**：应为「各向同性（isotropic）」，字幕吞了否定前缀，语义正好相反。
- **「访问权限时对齐的盒子 s」**：应为 axis-aligned（轴对齐）盒子，差异定义要求轴对齐。
- **「莱曼和」「反函数方法」**：分别是黎曼和（Riemann sum）、逆变换采样（inverse CDF sampling）。
- **「区域光圈图像」**：应为 zone plate（波带片），是检验采样质量的标准测试图。
- **「辐射度法既不一致也不无偏」**：双重否定造成混乱，原意是「不一致且有偏」；「差异 / 离散度」混用同理，都指 discrepancy。
