# P15 颜色

## 一句话概括

本集从「颜色是什么」这一看似幼稚的问题出发，把颜色还原为光的**光谱功率分布**（emission spectrum）与物体**反射/吸收光谱**（absorption / reflection spectrum），再讲人眼只有 S/M/L 三种视锥细胞，因此完整光谱被压缩成三个数、并因此产生了**元色**（metamer）现象；最后落到工程层面——色彩模型 vs 色域、加色与减色、RGB/HSV/XYZ/Lab/十六进制、Y'CbCr 下采样、CIE 1931 色度图、伽马校正，并预告下一讲辐射度量学。

## 本集主题与目标

讲师一开场就自问：颜色明明是「幼儿园就学过」的直觉事物，为什么要花一整节课去精确刻画它？答案是：颜色在日常生活中处处会「背叛直觉」，而只要不建立正确的心智模型，这些现象就会变成无法解释的神秘事件。

具体目标有四个：

1. **建立颜色的物理与生理模型**——颜色 = 电磁波频率（或波长）；光谱是颜色的根本描述，今天讲的所有编码方式都只是它的「便捷近似」。
2. **解释颜色为什么难以复现**——同一块颜料在商店和家里看着不一样、屏幕与打印不一致、日落照片「没内味儿」，都需要用发射光谱 × 反射光谱 × 人眼响应这三步来解释。
3. **给出数字化颜色的工程手段**——色域、色彩模型、加色/减色、HSV、XYZ、Lab、十六进制，以及各自的取舍（便于人指定 vs 便于压缩 vs 便于跨设备转换）。
4. **为渲染铺垫**——结尾明确说接下来要讲辐射度量学（radiometry）、光线与相机、材质散射，逐步搭建 photorealistic rendering。

## 核心概念

- **颜色即频率**：光是振荡的电场与磁场，颜色就是这个振荡场的频率。频率与波长互为倒数关系，两者描述同一件事但物理量不同。这是全课最关键的视角转变：颜色从「感觉」变成「可测量的物理量」。
- **可见光谱（visible spectrum）**：人眼只对很窄的一段波长敏感，大约覆盖红、橙、黄、绿、蓝、靛；两端之外是紫外线与红外线，再往外是 X 射线与微波。我们看不见它们，但它们本质上有「频率」，也就可以有「颜色」。
- **白色不是一种颜色**：白光不是单一频率，而是所有可见频率的混合。太阳的发射光谱在可见光区间有一个峰值——讲师由此解释人眼为何只敏感这一段：要捕捉阳光最强的那部分。
- **发射光谱 vs 吸收光谱**：发射光谱给出每个频率**产生多少光**（光源、太阳核聚变、热辐射）；吸收光谱给出白光照射时每个频率**被吸收多少**，未被吸收的部分即被反射。描述颜料、墨水、墙面要用后者。
- **反射光模型**：最终到达眼睛的强度 = 光源在 ν 处的强度 × 物体在该 ν 处的反射率。讲师用一个「偏绿黄的光源」照「反射红光的表面」的例子说明：结果是每个频率相乘后几乎只剩少量红橙光，这就是商店与家里色调不一致的算术来源。
- **视杆细胞与视锥细胞（rod / cone）**：视杆细胞约 1.2 亿个，暗环境下只测强度、不分颜色；视锥细胞约 670 万个，明视觉下分工测色。二者数量悬殊约 1 亿 vs 700 万，是「人眼对亮度远比颜色敏感」的生理依据。
- **视锥细胞分布不均**：中央凹视锥密度最高，向周边迅速下降，故**周边色觉很差**；讲师给出家庭实验：把彩色马克笔从视野中心极缓慢移向边缘，让人猜颜色，会猜得很差。另外视神经出口处无视感细胞，形成**盲点（blind spot）**，大脑自动填补。
- **S/M/L 三种视锥**：不用 RGB，而按短、中、长波长命名。M 与 L 曲线形状非常接近且集中在偏绿区域，约 64% 是 L 锥、32% 是 M 锥；讲师给出的解释是「优先捕捉最可能见到的光」——太阳光谱在绿区最强。
- **眼睛只测三个数**：视网膜实际计算的是入射光谱与各自响应函数的三个积分，大脑并不知道完整曲线。无论光谱含多少波长，输出只有三个电信号。这是后面所有色彩科学的总闸门。
- **元色（metamer，字幕写成「元色」）**：两条不同光谱经积分后得到相同的 S/M/L 响应，被感知为同一种颜色。曲线数远多于面积数，所以元色必然大量存在。它既让色彩复现变便宜（不必复刻真实光谱，混油墨「骗过眼睛」即可），也制造无数意外（灯与颜料的组合效果与预期不符）。
- **高光谱相机（hyperspectral camera）**：通道数远多于 3（十几条窄带响应），能分辨人眼分不清的光谱差异。用于钞票/护照的防紫外线油墨防伪、艺术史中鉴定颜料与赝品、从太空遥感区分植物种类。
- **色域（gamut）与色彩模型（color model）**：色域是「调色板上所有可选颜色」的集合，色彩模型是「给这些点命名的方法」。同一个赭石黄可以用名字指定，也可以用 RGB 三元组指定，且可能取自不同的色域。
- **加色与减色模型**：加色用于发光体（RGB 三盏灯叠加，红+绿=黄，红+蓝=品红）；减色用于吸收光的物体（CMYK），每次上色都在「去掉」某些波长。讲师纠正了一个术语：减色模型更准确的名字是**乘积色模型**（multiplicative），因为本质是逐频率相乘。
- **为什么需要 K（黑）**：青、品红、黄理论上叠加应为黑，但靠混色很难得到足够深的黑，而黑色是印刷里的常用色，所以额外加一罐黑墨。这是效率而非理论上的要求。
- **HSV**：hue（色相）、saturation（饱和度）、value（明度）。它更贴合人直接挑颜色的直觉——想让颜色「更灰」就降饱和度，而不是在三个 RGB 通道间手算。
- **XYZ 与 Lab**：XYZ 是与人类感知挂钩的数值化模型，Y 代表亮度，X、Z 表示色度。Lab 则是在 XYZ 上做**感知均匀性（perceptually uniform）**改造：参数等量变化应对应感知上的等量变化。
- **十六进制编码**：`#RRGGBB`，每通道 8 位（0–255），用 0–9 加 A–F 两个字符编码 256 个值。`#FF6600` 即满红 + 中绿 + 零蓝，呈橙色。单字符 16 值、双字符 256 值，是把十进制「顺手」扩展到十六进制的结果。
- **潘通（Pantone）与蜡笔模型**：非连续色域的命名式规范，潘通以约 1114 种标准色覆盖建筑等行业的涂料选色，可由 13 种标准参考颜料配出；蜡笔模型用「桉树」「雪松」「郁金香」这类名字，纯为人机便利。
- **Y'CbCr**：现代数字视频常用，Y' 为亮度，Cb/Cr 为相对灰轴偏离的色度（蓝—黄、红—青）。本集用它演示压缩：色度通道各下采样 20 倍，样本量减少 400 倍，亮度保持全分辨率，重建后肉眼几乎无感——只在颜色快速变化处出现块状伪影，用双线性滤波替代最近邻即可柔化边缘。
- **CIE 1931 色度图（chromaticity diagram）**：标准参考色域，几乎覆盖全部可见颜色；sRGB 是大多数显示器支持的三角形子集，也是日落照片不如肉眼好看的原因之一（丢掉了色域外的大量鲜艳色彩）。
- **麦克亚当椭圆（字幕作「麦凯布椭圆」）**：色度图上标注「在该椭圆内察觉不出差别」的区域，用于界面设计和计算机图形中判断两种颜色是否真的可区分。
- **伽马校正（gamma correction）**：老式 CRT 中电压与光强近似 $y \propto v^\gamma$ 的非线性关系，直接存亮度当电压发送会得到偏暗的图像，解决办法是发送前先取 $1/\gamma$ 次幂。虽然 LCD 已近似线性，但相机 RAW 与色彩管线仍要考虑它。

## 关键公式 / 算法 / 数据结构

- 频率与波长：$\nu = 1/\lambda$（两者互为倒数，描述同一个物理量）
- 光源发射光谱 $f(\nu)$ 与物体反射光谱 $g(\nu)$，则到达眼睛的光强度：

  $$I(\nu) = f(\nu)\cdot g(\nu)$$

- 传感器/视锥细胞的响应（对连续光谱积分）：

  $$r = \int f(\lambda)\, s(\lambda)\, d\lambda$$

  眼睛得到三个值 $S, M, L$ 分别对应三种响应函数；条件是两光谱在此积分下相等，即为元色。
- 热辐射与伽马：$y \propto v^{\gamma}$，校正时发送 $v^{1/\gamma}$（例如 $\gamma = 2.5$ 时取 $0.4$ 次幂）。
- Y'CbCr 下采样流程（算法）：亮度通道保留全分辨率 → 两个色度通道各 20 倍下采样 → 上采样后与亮度合成；上采样核从最近邻改为双线性以减少块状伪影。

## 讲解脉络

1. **动机：颜色为什么需要精确化**（商店涂料 vs 家墙、电子卖场的显示器差异、屏幕转印刷的彩虹伞变得黯淡、天文与地质中的颜色解读、艺术中对日落色调的夸张）。讲师用一种「反直觉现象清单」的方式铺出全天讨论的必要性。
2. **颜色的物理定义**：从麦克斯韦方程出发，带电粒子运动产生电磁场，振荡频率即颜色；用老式电炉从黑→暗红→橙→黄的变化引出热辐射；用热成像说明普通物体也在发光，只是落在可见光谱之外；由太阳光谱峰值解释可见光谱范围。这一步把「颜色」完全还原为物理量。
3. **光谱**：先区分发射光谱（光源发多少）与吸收光谱（白光下吸收多少），用叶绿素「吸收红蓝、反射绿」的例子把吸收光谱「翻译」成颜色；再对比日光、白炽灯（偏暖红）、荧光灯（尖刺状、感觉病态）的发射光谱，指出买灯泡其实就是匹配光谱，而节能灯是「欺骗眼睛」的产物。核心论点是：光谱是颜色的根本描述，其余一切只是近似。
4. **发射与反射的相互作用**：给出 $f(\nu) \times g(\nu)$ 的简单模型，用绿光照红色反射面的例子演示结果，说明色彩复现为何困难——而且此时还没考虑感知。
5. **人眼与感知**：从裙子之争（蓝黑 vs 白金）切入主观性；讲眼球作为「更复杂的针孔相机」、倒像、大脑翻转；讲视杆/视锥、数量悬殊、中央凹与周边色觉、盲点，以及那个马克笔实验；再讲 S/M/L 响应曲线、积分后只留三个数，由此推出元色；用防伪油墨和高光谱相机展示「三通道之外的世界」。这一节是整集的转折：从物理进入生理与心理。
6. **工程编码**：色域 vs 色彩模型、加色/减色与 CMYK 的 K、HSV、XYZ、Lab、十六进制 `#RRGGBB`、潘通与蜡笔模型；随后讨论颜色模型对混合/覆盖运算与压缩效率的影响，落到 Y'CbCr 的 400 倍色度压缩演示。
7. **色域与转换难题**：CIE 1931 色度图、sRGB 三角形、打印暗淡的实例、设备间转换为何「理想方法不可行」、色彩管理为何很难；补充麦克亚当椭圆、色觉差异与可访问性设计。
8. **两处收尾补充**：伽马校正（硬件层面的非线性）、视觉调节（adaptation）——国旗反相色残像实验说明神经元测量的是**变化**而非绝对值，随后预告辐射度量学。

## 重点结论

- 光谱（强度或吸收率随频率的变化）是颜色的唯一完备描述；RGB/CMYK 等一切编码都是其廉价近似，只以 RGB 三元组的直觉思考颜色，必然在现实中被某些现象「打脸」。
- 「感知到的颜色 = 发射光谱 × 反射光谱 × 人眼三通道响应」这条链上任何一环变化都会改变结果，这就是同一款漆在店里与家里不同、屏幕与打印不同的根源。
- 人眼只有三个自由度，因此元色不可避免。这既是色彩复现能便宜实现的基础，也是灯光与颜料组合频频出错的原因。
- 亮度通道承载了人眼最敏感的信息，颜色通道可以大幅压缩——这是 JPEG、Y'CbCr、视频编码的总设计原则。
- 色彩管理之所以难，是因为既要跨不同设备（显示 vs 打印）的不同色域，又要面对感知本身的非线性、非均匀与个体差异。
- 颜色模型的选择不是审美问题，而是三个工程目标的权衡：人是否容易指定、数值范围是否被充分利用、色域是否覆盖目标任务。

## 字幕含糊或可能有误的地方

- **「元色」**：应为 **metamer / metamerism**，标准中文译作「同色异谱」或「条件等色」。「元色」在中文色彩学里不是通用术语，听起来像「原色」，容易误解，建议改译「同色异谱色」。
- **「麦凯布椭圆」**：几乎可以确定应为 **麦克亚当椭圆（MacAdam ellipse）**，即色度图上等感知差别的椭圆。「MacAdam」被转写成「Mccabe/MacCabe」再译成「麦凯布」，属转写误差。
- **「pouch 桥」**：从上下文（顶部有绚丽 RGB 光效、底部是打印效果预览）看，应是某张带有霓虹灯/彩色桥的照片，属于专名识别失败，无法还原，不影响论点。
- **「CIE 1934」**：应为 **CIE 1931**，前后文两处自己就出现过 1931，属于口误或转写错误。
- **「ML 是这个模型」**：指人眼 S/M/L 视锥响应模型，字幕把 S 听漏了，读作「ML 模型」容易与机器学习混淆。
- **「Y'CbCr 下采样二十倍，样本量减少四百倍」**：二十倍 = 20×20 个像素合并为一个色度样本，即 400 倍，逻辑自洽；但常说的 4:2:0 只是 4 倍压缩，讲师在此处是为了放大说明效果，不是标准格式。
- **「频率等于波长的倒数」**：严格说是 $\nu = c/\lambda$，字幕省略了光速 $c$。在真空中取 $c=1$ 的习惯下不算错，但作为公式应补上。
- **「伽马是 2.5，将值提升到 0.4 次方」**：$1/2.5 = 0.4$ 正确；但传统 NTSC/SMPTE 显示伽马常写作 2.2（sRGB 近似为 2.4 带线性段），2.5 是讲师举例，不必当作标准值。
- **「减色模型更准确叫乘积色模型」**：这是一处有价值的术语澄清，但后续文字又回到 CMY 讨论，读者需注意「减色」与「吸收」是同一件事的两种说法。
- **「叶绿素也会吸收红色光」**：原话正确，但随后讲师顺带说「有时候人们说植物其实是红色的」——这是玩笑性的反讽（植物反射绿光），字幕未标明语气，读起来容易错懂。
- **「调节作用」**：指 **adaptation（视觉适应）**，后文用于解释国旗残像，翻译本身可接受，但与「accommodation（眼球调节）」中文撞词，需按上下文理解为「神经适应性」。
- 通篇有大量口语重复（如「需要认识到的重要一点」重复两次）与断句混乱，已在整理时合并，不影响语义。
