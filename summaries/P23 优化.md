# P23 优化

## 一句话概括

本集把“数值优化”作为与数值积分并列的第二个通用动画引擎：先用目标函数 $f_0(x)$ 把问题写成“标准形式”，讨论全局/局部极小值的存在性、唯一性与最优性条件（梯度、海森矩阵、KKT），再引出凸优化与凸二次这一“好问题”，最后落到梯度下降、牛顿法以及逆向运动学（inverse kinematics, IK）这一图形学实例。

## 本集主题与目标

上一集用动力学求解 $f=ma$，只要建立运动方程、用差分替代时间导数逐步前推，就能用很简单的模型“免费”得到复杂有趣的运动。本集提出同一位置的另一个通用工具：**数值优化**——写一个量化“解有多好/多坏”的目标函数，然后沿着函数值下降的方向改进解。

讲师明确强调两点：其一，优化不只服务动画，图像处理、几何、渲染乃至整门课涉及的内容都在反复求解优化问题；其二，本集大部分时间在讲**抽象的数学结构**（存在性、最优性条件、凸性、收敛行为），最后才用 IK 把理论接回图形学，为期末作业做铺垫。

## 核心概念

- **优化问题（optimization problem）**：在“可行的所有可能性”中找最好的解，通常带约束（预算、时间、长度等）。等周问题（Dido 公主用牛皮绳围地）是最早的经典例子之一：固定周长下围出最大面积，答案是圆——这同时给出“目标 + 约束”的原型。
- **离散 vs 连续优化**：离散问题的解集是离散集合（元素有限或与整数一一对应），如“炖菜放哪三种蔬菜”，朴素做法是穷举所有组合，指数级爆炸；连续问题变量可取实数（如“煮鸡蛋最佳温度”），无法穷举，需要另一种策略。这是区分解法族群的第一把尺子。
- **NP 难（NP-hard）**：旅行商问题（TSP）是典型——要拜访所有城市、总路程最短，大规模下没有已知多项式算法。但离散问题并非都难：最小生成树（minimum spanning tree）就是图问题，有 Prim、Kruskal 这类巧妙算法在合理时间内求解，穷举所有子树则会爆掉。
- **标准形式（standard form）**：标准写法是 $\min_x f_0(x)$，受不等式约束 $f_i(x)\le b_i$ 约束。讲师强调“大多数连续优化问题都能归一为这种形式”，于是所有图形学问题可以共用一套求解器；优化软件正是这样工作的：先做转换，再交给只认标准形式的求解器。
- **目标函数 / 损失函数**：$f_0$ 接收 $\mathbb R^n$ 中的参数向量，返回一个实数“打分”，本质是“x 有多糟糕”。最大化问题取反号即化为最小化；等式约束 $g(x)=c$ 用两条互补不等式刻画：$g(x)\le c$ 且 $g(x)\le -c$（即 $g(x)\ge c$），可见标准形式并不限制表达力。
- **全局最小值 vs 局部最小值**：全局最小是在所有可行点中最优；局部最小是邻域内最优，无法用小扰动改进。这并非纯粹的学究区分：蛋白质折叠到的是能量**局部**极小构型，而这个形状恰恰决定细胞功能，全局最小反而未必“更好”；机器学习中几乎从得不到全局最优，但局部极小的导数条件带来了良好行为。
- **存在性的三种失败方式**：① 目标无下界（$\min x$，x 一直向左）或约束不可行（同时要求 $x=1$ 与 $x=-1$，或两个不相交约束区域）；② 最优值存在但**取不到**（在实数上最小化 $e^{-x}$，只能无限逼近 0，没有最小化点，因此上集“取所有可行点中最小的”并不总成立）；③ 即使目标有界、可行集非空仍可能失败。
- **两个充分条件**：极值定理（extreme value theorem）——目标连续 + 可行域紧致（闭合且有界）；强凸性（strong convexity）——沿任意方向远离原点函数值趋于正无穷。二者只保证存在，不是必要条件。
- **最优性条件（optimality conditions）**：局部最小的检验分一阶、二阶两步——梯度为零（临界点）只是必要条件，还要海森矩阵半正定，才能排除最大值与鞍点。无约束时就这么简单。
- **KKT 条件**：有约束时上述条件失效（“薯片”函数的两个最优点梯度不为零），一般条件变为 Karush–Kuhn–Tucker 条件，除对 x 求导外还引入**对偶变量** λ，用来解释点是否处于最优。本集不深入，只说明“约束问题的最优性条件应该去查 KKT”。
- **凸优化（convex optimization）**：凸集（Set S 中任意两点的连线仍在 S 内）+ 凸函数（任意两点连线位于函数图像之上），加上强凸要求严格位于上方。好处是：总能得到最优解、不会掉进坏局部极小、**结果不依赖初始猜测**、算法行为可预测；代价是收敛可能慢、复杂凸问题仍很昂贵。凸二次问题是图形学中最常见的一类。
- **梯度下降（gradient descent）**：沿负梯度方向迭代，等价于用前向欧拉（forward Euler）离散化一个 ODE。延续上集“时间步长不能太大，否则单摆发散”的教训，步长 τ 需要线搜索或取得足够小，步长过小又会收敛很慢。
- **牛顿法（Newton's method）**：用海森矩阵逆预条件梯度，把“细长山谷”拉成圆碗，因此收敛极快；但海森矩阵不一定正定，可能朝鞍点走。求根版与优化版本质是同一算法。工程上还有拟牛顿法（quasi-Newton）、信赖域（trust region）、L-BFGS 等。
- **正向运动学 / 运动链（kinematic chain）**：骨骼、关节组成层级结构，关节有自由度与角度限制；给定关节角算末端位置是正向问题，给定末端目标反推关节角就是 IK，可用“末端位置与目标的距离”的平方作目标函数做梯度下降。

## 关键公式 / 算法 / 数据结构

标准形式：

$$\min_x f_0(x),\quad \text{s.t. } f_i(x)\le b_i,\ i=1..m$$

等式约束的转化：$g(x)\le c$ 与 $g(x)\le -c$。

一维局部极小：$f_0'(x^\*)=0$ 且 $f_0''(x^\*)>0$。

多元无约束最优性条件：

$$\nabla f_0(x^\*)=0,\qquad \nabla^2 f_0(x^\*) \succeq 0\ (\text{半正定, } u^\top H u\ge 0\ \forall u)$$

凸二次目标（$A$ 半正定）：

$$f_0(x)=\tfrac12 x^\top A x - b^\top x,\qquad \nabla f_0 = Ax-b = 0 \iff Ax = b,\qquad \nabla^2 f_0 = A\succeq 0$$

即“解线性方程组 = 找碗底”。半正定时解可能是一条线（“管状”），正定时是唯一碗底。

梯度下降（连续与离散）：

$$\dot x(t) = -\nabla f_0(x(t)),\qquad x_{k+1}=x_k-\tau\,\nabla f_0(x_k)$$

牛顿法：

$$x_{k+1}=x_k-\tau\left[\nabla^2 f_0(x_k)\right]^{-1}\nabla f_0(x_k)$$

二维运动链（复数写法更简洁）：$p_1 = p_0 + e^{i\theta_0}u_0$，$p_2 = p_1 + e^{i(\theta_0+\theta_1)}u_1$。

IK 目标函数：$f_0(\theta)=\tfrac12\,\|\tilde p_n - p_n(\theta)\|^2$，对 $\theta$ 做梯度下降。

## 讲解脉络

1. **动机**：接上集数值积分，提出第二个通用工具——优化；举等周问题、角色平衡、对称化、3D 打印陀螺仪、纸飞机气动优化等例子，说明“目标→打分→改进”的普适性。
2. **分类**：离散 vs 连续。用炖菜原料选配与煮鸡蛋温度作“傻瓜例子”建立直觉，再以 MST（易）和 TSP（NP 难）对比，说明离散问题靠聪明算法而非穷举。
3. **标准形式**：$\min f_0$ 加不等式约束，演示最大化取反、等式拆两个不等式，强调标准化的价值在于“一个求解器解决所有问题”。
4. **解的存在性**：用 $x_1^2-x_2^2$ 在单位圆盘、$\min x$、零目标+矛盾约束、$\min e^{-x}$ 逐个击破“优化总有解”的直觉，最终给出极值定理和强凸两个充分条件。
5. **最优性条件**：先一维（导数+二阶导），再推广到梯度 + 海森矩阵；指出约束下不成立，引出 KKT 与对偶变量 λ。
6. **凸优化与凸二次**：定义凸集、凸函数、强凸，说明为何是“好问题”；再推导二次型的 $Ax=b$ 与三种 A 的图像（碗 / 管 / 鞍）。
7. **求解算法与效率**：梯度下降的 ODE/欧拉视角、步长控制与线搜索（提及“莫尔维德法”），细长山谷导致振荡的缺陷，牛顿法的几何解释及其非凸风险，最后承认“没有通用最优算法”，推荐多试求解器、读文献、拟牛顿/信赖域/L-BFGS。
8. **图形应用 IK**：从关键帧动画的痛点切入，讲运动链、正向运动学、二维链的复数表达，再用少量角度梯度下降驱动整条骨骼抓取物体，并预告下集偏微分方程。

## 重点结论

- 优化与数值积分并列，是把“艺术家手工劳动”转成“计算”的第二条通用路径。
- 大多数连续优化问题可归为标准形式，标准化的意义是工具复用。
- “解存在”远非理所当然：无下界、不可行、下确界不达到都会让最优解消失；极值定理与强凸只给出充分条件。
- 梯度为零只是候选点，必须用海森矩阵半正定排查鞍点与最大值；有约束时改用 KKT 条件并引入对偶变量。
- 凸问题的核心价值不是“快”，而是**不依赖初始化、结果可保证**。
- 图形学中最常见的凸二次问题本质上就是解线性系统 $Ax=b$；平凡无约束二次问题“生活美好”，真实问题却大多非凸。
- 梯度下降只看局部信息，在细长山谷里会来回振荡；牛顿法用海森矩阵的逆把山谷拉成圆碗，凸问题上通常五六步即可收敛。
- 没有万能算法：必须根据问题结构选择求解器，并实际试跑。

## 字幕含糊或可能有误的地方

- “迪多公主”/“有序的故事”：应为 Dido（狄多女王）的“牛皮割条圈地”典故，“有序的故事”疑为“伊丽莎的传说”之类识别错误，不影响理解。
- “等周问题”处“牛皮带/牛皮绳”混用，通读可知是同一根绳子被切成极细的条。
- “普里姆算法克鲁斯卡尔算法”：即 Prim 与 Kruskal，正确。
- “莫尔维德法”：应是 **Armijo 准则**（回溯线搜索的充分下降条件）被误转写，字幕中无其他线索，判断存疑。
- “a U 大于等于 u 抱歉应该是对于所有 u 大于等于零”：口误，正确表达为 $u^\top A u\ge 0,\ \forall u$。
- “从实数到实数”处应为 $f_0:\mathbb R\to\mathbb R$，“从下方有界”一词出现次数较多但表述前后有重复。
- “我们之前已经见过这样的例子在讨论二次误差简化时”：应为 **二次误差度量（quadratic error metric, QEM）边收缩简化**，讲师口中的“简化”指 mesh simplification。
- “对 x₁ 和 x₂ 求二阶导数”：应为 $\partial^2 f/\partial x_1\partial x_2$ 等混合偏导，表述顺序略乱。
- “极值定理要求紧致域…在某种意义上是有限的”：口语重复，实质是“闭且有界”。
- “这次要谈谈偏微分方程”：与前面“下次回到微分方程”并存，指向清晰，即下一次从 ODE 进阶到 PDE。
