# P16 辐射度量学

## 一句话概括

本集把「光」当成一袋袋飞行的光子（小橡胶球）来计数，用辐射能、辐射通量、辐照度、辐亮度四个层层细化的量，量化光在时间、空间、方向、波长上的分布，并推出 Lambert 余弦定律、$n\cdot l$ 着色、平方反比衰减、光场与环境遮蔽等渲染常用工具。

## 本集主题与目标

本集是渲染方程之前的地基课。上一集讲清了颜色的物理来源（波长），但只知道波长无法成像，还必须知道每个点「收到多少光」。辐射度量学（radiometry）做的就是为电磁辐射建立单位与测量体系。适用范围被明确限定：只取宏观的几何光学（geometric optics）模型，假设光子沿直线传播、波长远小于物体尺寸，故忽略衍射（diffraction）、干涉等微观效应；并假设光传输处于稳态（steady state），开灯后瞬间平衡，不追踪逐光子的时间动态。目标有二：物理正确地量化光照；用单位做检查，把渲染代码的 bug 拦下来。

## 核心概念

- **几何光学模型（geometric optics）**：把光看成沿直线飞行的光子流，用射线与场景求交判断可见性。牺牲衍射、干涉等小尺度现象换取可计算性。
- **名称不等于知识（Feynman 的鸟）**：讲师用费曼讲褐喉鸫的故事说明——知道一只鸟在所有语言里的名字，对它仍一无所知。术语多且吓人，但要先搞懂每个量「在数什么」，再接受名字与单位。
- **辐射能（radiant energy, $Q$）**：一段时间内撞击某表面的光子总能量，单位焦耳。字幕的直观说法是「总撞击次数」——场景里 40 次光子撞击就是这份能量。
- **辐射通量（radiant flux / power, $\Phi$）**：单位时间的能量，单位瓦特，即「每秒撞击次数」。稳态下每个时刻分布相同，故记录每秒比记录任意长时间段的总量更有意义。
- **辐照度（irradiance, $E$）**：单位面积的通量，单位 $\mathrm{W/m^2}$。图像的本质就是辐照度图：每个像素记录一个小区间接收到的每秒撞击数。
- **立体角（solid angle, $\Omega$）**：平面角是弧长比半径，立体角是球面面积比半径平方，单位球共 $4\pi$。它衡量物体在天球上占多大一块；日月看起来一样大，就是因为大而远的太阳与小而近的月球张角相同。
- **辐射亮度/辐亮度（radiance, $L$）**：单位时间、单位面积、单位立体角的能量，单位 $\mathrm{W/(m^2\cdot sr)}$，即辐照度对立体角的「密度」。它是渲染的核心量：真空中沿一条光线 radiance 恒定，故一条光线只需存一个值，光场、针孔相机、光线追踪都由此成立。
- **入射与出射辐亮度（$L_i$、$L_o$）**：同一点同一方向，进入与离开的光一般不等（灯泡出射远大于入射），这一区分是下一集讨论材质的直接入口。
- **光场（light field）**：为空间中每条光线分配一个辐亮度值，四维参数化 $(x,y,\theta,\varphi)$。普通相机只截取一小片；微透镜阵列（microlens array）能采集更多切片，从而事后重新对焦或换视角。
- **各向同性点光源（isotropic point light）**：向各方向均匀发光，强度 $I$ 为总通量除以 $4\pi$。现实中不存在理想点光源，它是数学抽象，却能自然导出距离平方反比衰减。
- **环境遮蔽（ambient occlusion）**：用半球均匀光源近似阴天，辐照度恒为 $L\pi$，差异全部来自遮挡，因此可把每点可见性「烘焙」进纹理。
- **光度学（photometry）**：辐射度量是物理量，光度学是其「以人为本」版本，用视见函数 $V(\lambda)$ 加权得到亮度（luminance）$Y$；对波长积分后颜色信息丢失。

## 关键公式 / 算法 / 数据结构

```text
光子能量:  q = hc / λ            # h 普朗克常数(J·s), c 光速(m/s), λ 波长(m) → 焦耳
能量:      Q = ∫ Φ dt                                    [J]
通量:      Φ = dQ/dt                                     [W]
辐照度:    E = dΦ/dA                                     [W/m²]
辐亮度:    L = dΦ / (dA·dω·cosθ) = dE / (dω·cosθ)        [W/(m²·sr)]
光谱量:    dE/dλ                                         [W/m³]
余弦定律:  E = (Φ/A)·cosθ = E0·cosθ
着色:      return max(0, dot(n, l))                       # n, l 单位向量
点光源:    I = Φ/(4π),  E = Φ/(4πr²),  E2/E1 = (r1/r2)²
微立体角:  dA = r²·sinθ dθ dφ,  dω = sinθ dθ dφ
半球:      E = ∫H² L·cosθ dω = L·π
面光源:    E = L·Ω⊥,  Ω⊥ = π·sin²α,  E = L·π·sin²α
光度学:    Y = ∫ L(λ)·V(λ) dλ
```

光谱功率分布（spectral power distribution）是再按波长细分的结果，单位 $\mathrm{W/(m^3)}$；再除以波长得到光谱辐亮度，能量至此被完全分解，颜色信息随之保存。余弦定律的直觉是：同一束光摊到更大面积 $A'=A/\cos\theta$ 上，单位面积光子变少，于是更暗更冷。

光度学换算 $Y=\int L(\lambda)V(\lambda)\,d\lambda$ 把光谱辐亮度按人眼视见曲线压成单值「亮度」，颜色信息被积分掉了。讲师补充：人眼并非单一静态模型（明暗视觉响应差别很大），建筑预可视化必须考虑这类感知现象。

光源一侧有两类常见抽象：定向光（directional light）位于无穷远、光线方向全同，只需一个常量方向 $l$，适合太阳；各向同性点光源强度 $I=\Phi/(4\pi)$，半径 $r$ 处 $E=\Phi/(4\pi r^2)$。真实灯具可用测光图（goniometric diagram）记录强度随角度的变化，业界已有现成数据可下载。

## 讲解脉络

1. **为何要量化光**：承接颜色课，指出渲染需要「每点接收多少光」与「有多少光到达相机」，故须建立物理精确的单位体系，并声明几何光学 + 稳态两条简化。
2. **命名与理解**：借费曼观鸟的故事强调术语只是标签，先理解「光子何时、何地、打了多少次」，再记名字与单位。
3. **四量逐级细分**：辐射能 →（除以时间）辐射通量 →（除以面积）辐照度；逐个给定义、直观图像与单位，并指出图像生成的目标就是估计每像素的辐照度。
4. **单位作为调试工具**：由光子能量给出焦耳，再用 $dQ/dt$、$d\Phi/dA$ 推出瓦特与 $\mathrm{W/m^2}$，顺带按波长分解得到 SPD。
5. **由余弦定律到着色**：用四季成因的反直觉提问（不是日地距离，而是地轴倾斜）说明斜射使光子摊在更大面积上，得 $E=E_0\cos\theta$，直接导出 $n\cdot l$ 与 $\max(0,n\cdot l)$ 的钳制。
6. **光源模型与衰减**：从定向光到各向同性点光源，用两个同心球面推出平方反比，并引出立体角与球面参数化。
7. **辐亮度与光场**：加上方向维度得到 radiance，说明其在真空中沿光线恒定，进而给出光场、微透镜相机与「先拍照后对焦」。
8. **应用与边界**：半球光照度积分与遮挡、环境遮蔽烘焙、屏幕空间环境遮蔽、面光源与测光图。

## 重点结论

- 四个辐射度量本质上是**同一个量的不同分解维度**：空间、时间、方向、波长；概念上不过是数光子，复杂之处全在术语与单位。
- 单位是渲染代码最便宜的调试工具：全程跟踪焦耳、瓦特、$\mathrm{W/m^2}$、$\mathrm{W/(m^2\cdot sr)}$，乘除几次后单位跑偏通常就说明代码错了。
- 辐照度 $E=E_0\cos\theta$ 是屏幕着色的根源——Lambert 项必须钳制到非负，因为「负能量」无物理意义，光源在表面背后时也不该再贡献亮度。
- radiance 的恒定性是整条光传输理论的主干：一条光线只带一个值，才有光线追踪、光场与针孔相机的等价性；一旦进入雾、烟等参与介质，这条性质就失效。
- 均匀半球光源下 $E=L\pi$ 处处相同，明暗完全由遮挡解释，这正是环境遮蔽可烘焙成纹理的原因；屏幕空间环境遮蔽则用深度缓冲中的邻近深度近似它。
- 面光源产生柔和光晕，比点光源更接近真实照明。图形学可以故意违反物理（线性衰减更好打光），但要物理正确就得遵循平方反比等规律。
- 术语有三套并行命名（物理学：能量/通量/通量密度；辐射度量学：辐射能/辐射功率/辐照度/辐射亮度；光度学：光通量/照度/亮度），记不住就回到「光子打在哪、多少、从哪来」这幅图。

## 字幕含糊或可能有误的地方

- 「辐射能密度是二除以 $\varepsilon$ 平方」：这是「2 次撞击除以面积」的小算例，「ε」应为表示微小面积的 $a$，不是标准术语。
- 「四倍 π 乘以强度乘以 π」：末尾「乘以 π」是重复误识，总通量就是 $\Phi=4\pi I$。
- 「太阳和月亮张角约六十微弧度」「五十乘以十五除以 π」：数字语义断裂。真实日月张角约 0.5°（约 9 毫弧度），字幕数字不可信；可保留的只有「立体角 ÷ 单位球面积 × 投影面积」这个算法。
- 「辐亮度是辐照度 $dE/d\omega$」：严格定义是 $L=d^2\Phi/(dA\,d\Omega\cos\theta)$，字幕稍后自己给了等价式，两版应合并理解，只写 $dE/d\omega$ 会漏掉 $\cos\theta$。
- 「$d\Omega$ 积分 0 到 2π 沿纬度、0 到 π 沿经度」：方位角与极角说反了，应为 $\varphi\in[0,2\pi)$、$\theta\in[0,\pi]$，结果 $4\pi$ 不受影响。
- 「平方波长的单位」「每平方米平方除以米」：转写混乱，正确为 $\mathrm{W/(m^2\cdot m)}=\mathrm{W/m^3}$。
- 「这些未讨论的光源方向 $l$ 的来源」：句子断裂，实为讲师自问「光照方向从哪来」，随后引入定向光。
- 「辐射度」「辐射亮度」「辐射通量密度」交替出现，应统一为 radiance、irradiance 的标准译名；「luminance / 亮度 $Y$」是光度学量，与 radiance 不同。
- 「均匀圆盘 α 是盘片在该点形成的夹角」：应为半张角（精确值 $\arctan(r/d)$）。「詹姆斯·卡贾」人名转写不可辨，无法确认出处，建议忽略；「在 $h^2$ 上 Ω」应为半球 $H^2$ 上的积分。
