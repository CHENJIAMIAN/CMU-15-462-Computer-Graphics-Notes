# P05 绘制三角形与采样简介

## 一句话概括

本集从"如何在屏幕上画一个三角形"出发，把光栅化（rasterization）定义为对三角形覆盖函数（coverage function）的采样与重建，先铺垫采样、重建、混叠与超采样，再落到"点是否在三角形内 = 三次半平面测试"这一原子操作及其硬件实现策略。

## 本集主题与目标

本集是光栅化系列的引子，目标有三层：一是定位，把光栅化与光线追踪（ray tracing）并列为"把内容呈现在屏幕上的两大技术"，说明各自擅长什么、代价几何；二是建框架，用管线（pipeline）描述图像生成——输入是顶点、三角形与顶点属性，输出是位图（bitmap），中间分若干阶段；三是深挖第一个阶段，即屏幕映射之后、属性插值之前的"三角形覆盖采样"，先在概念上解释成采样问题，再讲工程上如何实现得足够快。

## 核心概念

- **光栅化（rasterization）**：对每个图元（三角形、线段、点）确定图像中哪些像素被点亮。直觉是"把连续形状盖到像素网格上，看哪些格子被盖住"。它重要，是因为极易并行与硬件化，现代 GPU 每秒可处理数十亿三角形。

- **光栅化的边界**：讲师直言它难以生成逼真的阴影、反射与光照，因此适合二维矢量艺术、卡通、字体设计和三维场景快速预览，不适合电影级写实渲染。

- **光线追踪（ray tracing）**：反过来对每个像素询问"哪些图元对该像素可见"。它更自然地产出写实图像，但可能数分钟甚至数小时才出一张图。

- **管线（pipeline）**：把计算拆成输入输出结构规整、高度可预测的若干阶段，从而可深度优化。它解释了为什么 GPU 能把"画图"做成专用机器。

- **为什么用三角形**：可近似任意复杂形状（类似像素之于图像）；三顶点永远共面，法线明确，利于光照；角点属性插值简单（引出重心坐标 barycentric coordinates）；统一为三角形后，所有形状、线条、点都归约为同一种高度优化的原子操作。

- **覆盖（coverage）与可见性（visibility）**：前者问"三角形覆盖了哪些像素"，后者问"多个三角形覆盖同一像素时谁离相机更近"。讲师用针孔相机（pinhole camera）模型统一两者：可以从针孔穿过像素向场景发射光线，看击中哪些三角形、谁最先被击中。

- **精确覆盖不可行**：覆盖比例看似直观（覆盖 10% 就显示 10% 红），但遇到相互穿透的三角形、非凸重叠区、半透明时会极难甚至无定义，于是转向近似积分——这是本集的核心转向。

- **采样与重建（sampling / reconstruction）**：采样把连续信号化为离散数值（音频每秒约 44,100 次是标准例子），重建由离散值恢复连续函数。二者是图形学的一般范式，不只用于光栅化。

- **走样/混叠（aliasing）**：采样不足时高频成分在重建中"伪装"成低频，产生虚假特征——音高扫频听起来上下起伏，图像出现锯齿（jaggies）、闪烁（flicker）、摩尔纹、车轮倒转。讲师说整个学期都会反复遇到它。

- **奈奎斯特-香农定理（Nyquist–Shannon theorem）**：若信号带限，采样率不低于最高频率两倍即可用 sinc 滤波器精确重建。但它依赖信号带限与滤波器无限支撑两个前提，而覆盖函数有硬边缘、含无限频率，sinc 又需对所有样本求和，所以不完美是常态。

- **超采样（supersampling）**：每像素取多个样本再平均，以被覆盖样本比例估计像素覆盖比例。4、16、1024 个样本效果依次变好但仍不完美。

- **半平面测试（half-plane test）**：三角形是三个半平面之交，判断查询点是否同时在三条有向边的同一侧即可。这是光栅化的原子操作。

## 关键公式 / 算法 / 数据结构

- 覆盖函数：

$$
I(x,y)=\begin{cases}1 & (x,y)\in T\\ 0 & \text{否则}\end{cases}
$$

光栅化即在像素采样点上求 $I$，像素值为 $N$ 个样本的平均：

$$
c_{\text{pixel}}=\frac{1}{N}\sum_{k=1}^{N} c(x_k,y_k)
$$

- 半平面判定：对有向边 $\overline{p_i p_j}$，用叉积符号判断点 $q$ 在左还是右：

$$
\text{side}(q)=(p_j-p_i)\times(q-p_i)
$$

三条边同号即在内部；样本恰落在边上时需"顶边/左边规则"（top-left rule）消除相邻三角形的缝隙与重复写入。

- sinc 重建滤波器：$\operatorname{sinc}(x)=\dfrac{\sin(\pi x)}{\pi x}$。

- 抗锯齿演示函数：$f(x,y)=\sin(x^2+y^2)$，原点附近平缓、远处环纹越来越密，用于展示采样无法解析的高频如何变成屏幕上并不存在的图案。

```text
inside(p0,p1,p2,q):
    return sign(cross(p1-p0,q-p0)) == sign(cross(p2-p1,q-p1))
        == sign(cross(p0-p2,q-p2))
```

## 讲解脉络

**一、两个范式。** 用"画三角形"这个看似基础的问题开场，点明它暴露图形学的深层挑战，随后把光栅化（按图元求像素）与光线追踪（按像素求图元）对立起来，为后文"覆盖 vs 可见"埋线。

**二、管线与立方体原型。** 从处理器、编译器的流水线类比讲起，强调阶段化即可优化；回顾第一讲的立方体例子（顶点加边 → 透视投影 → 连线 → 图像），再说明现代管线输入变成"点、三角形加属性（颜色、纹理坐标）"，输出是含颜色、深度、透明度的像素数组，实际执行者是 GPU。

**三、为什么是三角形。** 四个理由依次铺开，并指出连点和线最终也被画成极细长的三角形，以此说明"统一到一种图元"带来的优化收益。

**四、管线高层草图。** 依次是变换与放置物体（人在房子里、房子在星球上）、投影到二维、覆盖采样（今天重点）、顶点属性插值与纹理、合并为最终图像。顺带说明 OpenGL、Direct3D、Vulkan 只是与各阶段通信的 API 封装，不是课程重点。

**五、从覆盖到采样。** 先用放大的像素与四个三角形发问"哪些覆盖了它"，引出覆盖比例，再指出精确比例不可行，于是讲一维音频的采样与重建、分段常数与分段线性的不足、提高采样率、双线性（bilinear）插值，最后定义覆盖函数，把光栅化明确为"在像素中心采样覆盖函数"，并强调边界情形必须有显式规则。

**六、混叠的系统化。** 借 $\sin(x^2+y^2)$ 与车轮倒转说明高频欠采样后伪装成低频；引出频率分解、奈奎斯特-香农定理与 sinc；再说明现实中做不到完美（非带限、无限支撑），走样因此是常态。

**七、超采样与硬件实现。** 先给超采样思想（棋盘格从 1 到 4、16、1024 个样本逐级改善），指出精确积分只对极少数函数可行；再回到实现：点是否在三角形内 → 三条有向边。策略按演进排列：增量/扫描线遍历（瓶颈常是访存而非算术，故要内存连贯）→ 包围盒并行测试（GPU 正为此设计）→ 块式检查与提前终止（全内或全外直接跳过，只细查边界）→ 分层递归四叉细分到 4 像素块。

**八、收束。** 用"采样—重建—混叠"总结，强调光栅化把屏幕绘图归约为三次半平面测试，并预告下集讲三维变换。

## 重点结论

1. 光栅化 = 对覆盖函数在像素网格上采样 + 分段常数重建；快来自管线可并行与硬件专精，弱来自难以表现真实光照。
2. 三角形胜在可插值、永远共面、可逼近一切、可统一优化。
3. 精确覆盖比例一般不现实，采样近似才是通用解，走样是其必然代价。
4. 奈奎斯特-香农给出完美重建的充分条件，但覆盖函数有硬边、不满足带限，实践中只能提高采样率逼近。
5. 三角形光栅化的原子操作是"点对三个半平面"；性能瓶颈在访存与边界处理，不在算术。
6. 边界规则必须由规范明确定义，不能依赖实现巧合，否则会出现缝隙或双写。
