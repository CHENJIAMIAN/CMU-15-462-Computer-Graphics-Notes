# P07 三维旋转与复数表示

## 一句话概括

本集从「变换由不变量定义」出发，说明三维旋转有 3 个自由度且不可交换，剖析欧拉角（Euler angles）的万向节锁（gimbal lock）缺陷，再用复数的几何化理解引出四元数（quaternion），展示它如何简洁编码旋转、支持平滑插值（slerp），并延伸到共形纹理映射与李群（Lie group）视角。

## 本集主题与目标

承接上一集关于空间变换（translation / rotation / scaling）的讨论，本集专门处理三维旋转。讲师的目标不是给一套公式让人背诵，而是：用「什么量保持不变」识别旋转；数清旋转需要几个参数，解释三维旋转为何不能交换顺序；把欧拉角、轴角（axis-angle）、复数、四元数放在一起比较，说明「没有唯一最佳表示，只有最适合当前问题的表示」；为后续光栅化管线中的相机与动画插值打基础。

## 核心概念

- **用不变量定义旋转（invariants）**：旋转保持长度与距离不变（书的两个角之间距离不变，无拉伸、无剪切），也保持手性不变（文字仍能从左到右阅读）。镜面反射（mirror reflection）同样保长度，却把文字翻转，所以不是旋转。这延续上一集的观点：变换由它保持不变的东西定义。
- **旋转默认固定原点**：说「旋转」时通常指某个中心点不动，否则那是「旋转 + 平移」。
- **三维旋转的自由度是 3**：把匹兹堡转到圣保罗，需纬度、经度两个数定位目标点；到达后还可绕「新城市所在的半径」自转一个角度而保持圣保罗不动，故共 3 个自由度。
- **二维旋转可交换（commutative / Abelian），三维不可交换**：二维只有一个角度，先转 40° 再转 20° 与反过来都等于转 60°；三维不然。讲师用水瓶演示：先绕 y、再绕 z、再绕 x 各转 90°，与先绕 z、再绕 y、再绕 x 的结果完全不同，「水洒得到处都是」。这正对应四元数乘法不交换。
- **欧拉角（Euler angles）**：把三维旋转拆成绕 x、y、z 的三次二维旋转再相乘。唯一优点是概念上极易理解；缺点是通式复杂、有万向节锁、插值不自然。
- **万向节锁（gimbal lock）**：当中间角 θy = π/2 时矩阵退化，θx 与 θz 只剩一个有效自由度，某个方向被「锁死」。讲师指出这对飞机操控、相机控制是灾难。
- **轴角表示（axis-angle）**：用单位轴 u = (ux, uy, uz) 加角度 θ 描述旋转，代入通用矩阵即可。它没有万向节锁，但公式难记；四元数会给出更轻的构造。
- **复数即二维向量 + 一种新乘法**：讲师主张忘掉「i 是 −1 的平方根」，改为几何定义：i 就是逆时针 90° 旋转，乘两次即翻转，于是 i² = −1。复数不过是把基向量 e₁、e₂ 改名叫 1 和 i，把坐标 (a, b) 写成 a + bi，加法、数乘照旧，只多一个乘法。
- **复数乘法的几何意义**：模长相乘、幅角相加。z₁ = r₁∠θ₁、z₂ = r₂∠θ₂，积为 r₁r₂∠(θ₁+θ₂)。于是「连续旋转」变成「角度相加」，天然处理超过 2π 的循环。
- **欧拉公式（Euler's formula）**：$e^{i\theta} = \cos\theta + i\sin\theta$，应直接读作「单位圆上从 x 轴出发转过 θ 的点」，即前文的 s(θ)。讲师提到「最美恒等式」$e^{i\pi}+1=0$，但明确不证明。
- **四元数（quaternion）**：哈密顿（Hamilton）想把复数推广到三维，多年未果，最终在过桥时顿悟需要四个分量而非三个。写作 $q = a + bi + cj + dk$，规则是 $i^2=j^2=k^2=ijk=-1$，乘法满足分配律、结合律，但**不交换**——恰对应旋转顺序有关。
- **四元数的标量-向量分解**：把四元数看成「一个标量 + 一个三维向量」（$a+\mathbf{u}$），乘法变得极紧凑，并天然包含点积与叉积。
- **用四元数表示旋转**：单位四元数通过共轭夹心作用于纯虚四元数 $x$，即 $q x \bar{q}$，得到绕某轴转某角的结果。共轭（conjugate）保持实部、翻转三个虚部，几何上相当于一种反射。
- **球面线性插值（slerp）**：在单位四元数 q₀、q₁ 间插值，取相对旋转 $q_0^{-1}q_1$，求其 t 次幂再左乘 q₀。这样旋转速度均匀、路径自然，克服了上一集极分解（polar decomposition）插值速度不均的问题。
- **共形映射（conformal mapping）与纹理坐标**：把曲面展平做纹理映射时，希望角度不被扭曲（图案上的直角在曲面上仍是直角），复数正是描述这类保角变换的自然语言；保角而允许尺度变化，也符合人眼近大远小的感知。
- **复/四元数分形**：对平面上每个点迭代复函数判断是否属于分形集合，把同样迭代搬到四元数即得三维分形。
- **李群与李代数（Lie group / Lie algebra）**：与轴角精神相近但性质更优，无万向节锁、操作非奇异，能编码大于 2π 的大角度，适合旋转平均与统计；核心工具是指数映射（exponential map，轴角→旋转矩阵）与对数映射（logarithm map，矩阵→轴角）。

## 关键公式 / 算法 / 数据结构

二维旋转矩阵（列向量 = 基向量旋转后的像）：

$$
R(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta\\ \sin\theta&\cos\theta\end{bmatrix},\quad
s(\theta)=(\cos\theta,\sin\theta),\quad s(\theta+\tfrac{\pi}{2})=(-\sin\theta,\cos\theta)
$$

复数乘法（展开并用 $i^2=-1$）：

$$
(a+bi)(c+di)=(ac-bd)+(ad+bc)i
$$

欧拉公式与极坐标乘法：

$$
e^{i\theta}=\cos\theta+i\sin\theta,\qquad
(r_1e^{i\theta_1})(r_2e^{i\theta_2})=r_1r_2e^{i(\theta_1+\theta_2)}
$$

四元数乘法（标量 + 向量形式）：

$$
(a,\mathbf{u})(b,\mathbf{v})=\big(ab-\mathbf{u}\cdot\mathbf{v},\;a\mathbf{v}+b\mathbf{u}+\mathbf{u}\times\mathbf{v}\big)
$$

纯虚情形：

$$
(0,\mathbf{u})(0,\mathbf{v})=\big(-\mathbf{u}\cdot\mathbf{v},\;\mathbf{u}\times\mathbf{v}\big)
$$

由轴 $\mathbf{u}$、角 $\theta$ 构造单位四元数，及旋转作用：

$$
q=\cos\frac{\theta}{2}+\sin\frac{\theta}{2}\mathbf{u},\qquad x'=q\,x\,\bar{q}
$$

球面线性插值：

$$
\operatorname{slerp}(q_0,q_1;t)=q_0\left(q_0^{-1}q_1\right)^{t}
$$

## 讲解脉络

1. **复习：旋转由不变量识别**。用旋转一本书说明长度、距离、可读方向不变，镜面反射翻转文字，由此区分旋转与反射，并澄清「旋转固定原点」。
2. **数自由度**。从「绕 x/y/z 三个角」的直觉出发，再用地球仪把匹兹堡转到圣保罗做几何论证：2 个数定位目标点，第 3 个数管到达后的自转。为后文「三个参数不等于三个独立有效自由度」埋下伏笔。
3. **顺序问题**。先给二维的正面例子（40°+20°），再用矿泉水瓶做两次不同顺序的 90° 旋转，得出「顺序错了会出大事」的工程警告。
4. **从零推导二维旋转矩阵**。定义 s(θ) 为 e₁ 转 θ 后的像，利用线性性把 a e₁ + b e₂ 写成 a·s(θ) + b·s(θ+π/2)，矩阵的列就是基向量的像，再用三角恒等式化简。讲师强调要记住矩阵「怎么来的」，而非背公式。
5. **欧拉角与万向节锁**。三个轴矩阵相乘得复杂通式；取 θy = π/2 使 cos=0、sin=1，矩阵退化成一个 2×2 块，只剩 θx 与 θz 的组合，实际只有一个有效转轴。由此判断欧拉角「唯一优点是直观」。
6. **轴角表示**。给出绕任意轴 u 转 θ 的通用矩阵，承认难记，但预告后面有更轻的构造法；随后「降维」到二维，用复数重讲旋转。
7. **复数的几何化重建**。先破除「i = √−1」的心理障碍，用「i 是 90° 旋转」重建直觉，得 i² = −1；再把复数定义为换了基名的二维向量，引入「模长相乘、角度相加」的乘法；用直角坐标展开验证，引入欧拉公式与极坐标形式；最后对比矩阵连乘与指数相加，说明复数表达更短、更好读、更好求导。
8. **四元数与插值**。讲哈密顿的故事与乘法规则，说明不交换正对应旋转不可交换；用标量+向量形式简化乘法，指出它包含点积与叉积；给出 $q=\cos(\theta/2)+\sin(\theta/2)\mathbf{u}$ 与共轭夹心公式；用 slerp 解决旋转插值，再延伸到共形纹理映射、分形与李群，收束于「没有唯一最佳表示」。

## 重点结论

- 旋转的本质是不变量（长度、距离、手性），不是某个矩阵长什么样。
- 三维旋转有 3 个自由度且**不可交换**；任何表示都必须面对「顺序」问题。
- 欧拉角直观，但表达式复杂、有万向节锁、插值路径怪异，不适合作为工程内部表示。
- 复数把二维旋转变成「角度相加、模长相乘」，把复合与求导都简化；$e^{i\theta}$ 应理解为「单位圆上的点」，而非指数函数。
- 四元数是复数的四维推广，构造极简，$q x \bar{q}$ 执行旋转，乘法不交换与旋转顺序相关完全自洽。
- slerp 提供均匀、自然的旋转插值，是四元数在图形学中最有价值的应用之一。
- 表示方法没有绝对优劣：矩阵、欧拉角、轴角、复数、四元数、李群各有适用场景，关键是识别问题该用哪种。

## 字幕含糊或可能有误的地方

- 「三维D你怎么看」「需要多少个数字来描述三维」——应为「三维（3D）旋转需要几个数」，属转写漏词。
- 「s(θ)+π/2」多次出现，实为 $s(\theta+\pi/2)$，即「再多转 90°」，不是 s(θ) 加一个常数。
- 水瓶实验的口令有断裂：「接着绕 z 轴旋转九十度……最后绕 x 轴旋转九十度」缺少中间姿态描述，「现在应该沿 x 轴方向指向」指代不明。判断：现场演示的口语被压缩，两轮顺序不同这一点可信，但细节不足以严格复现。
- 「i 乘 j 乘 k 也会回到负一方向」——应为 $ijk=-1$；后文「将所有的 ij 乘积转换为负一」也不准确，$ij=k$ 而非 $-1$，只有 $i^2=j^2=k^2=ijk=-1$。
- 「q 的共轭 X 乘以 q」——标准写法是 $q x \bar{q}$（共轭在右）或 $\bar{q}xq$（共轭在左），取决于主动/被动约定；字幕把共轭放在左侧，需注意两种约定给出相反转向。
- 「四元数的逆就是共轭后除以模长平方」——正确，即 $q^{-1}=\bar{q}/|q|^2$；但对单位四元数直接取共轭即可，字幕未点明。
- 「商和幂运算」——应理解为「先做商 $q_0^{-1}q_1$，再取 t 次幂」，是简写而非两个并列运算。
- 「李氏视角代数与李群」——应为「李代数与李群（Lie algebra and Lie groups）」，「李氏」是「Lie」的音译误写。
- 「极分解的方法然后在极分解的不同分量之间进行插值」——措辞含混，但「线性插值导致速度不均匀」的判断与后文 slerp 的动机一致。
