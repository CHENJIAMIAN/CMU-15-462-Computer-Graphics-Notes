# P03 线性代数（预）复习

## 一句话概括

本集用"向量就是一支小箭头"贯穿始终，从向量空间的公理、范数与内积讲到线性映射、基、傅里叶分解和线性方程组，反复强调先建立几何图景，矩阵只是最后的数值编码。

## 本集主题与目标

这是数学复习部分的第一讲，下一讲是向量微积分（vector calculus）。讲师把线性代数定位为几何、物理与计算之间的桥梁：问题一旦写成线性系统，就能交给高度优化的数值求解器，流体模拟、动画和几何处理都建立在它之上。

目标不是复述定义。讲师反对"老师说是定义就照着用"，要求对每条规则追问它从哪来、几何上对应什么、能不能画出来。具体分四层：说清向量与坐标系；把范数、内积提升为抽象定义并推广到函数、图像和声音；理解线性映射、张成空间、基与正交化；理解线性方程组的存在性与唯一性，以及为什么"用矩阵思考"会误导人。

## 核心概念

**向量与坐标（vector / coordinate system）**：向量是一支箭头，编码方向与大小，二维可用极坐标 $(\theta,r)$ 描述。线性代数中的向量不带"从哪点出发"的信息，所有向量共享原点；带基点的向量属于微分几何语境。同一向量可用极坐标或笛卡尔坐标编码，但 $\theta$ 依赖参考方向，长度不依赖参考方向却依赖单位，因此不同坐标系的数值绝不能直接比较——讲师说这是图形代码大量 bug 的根源。笛卡尔坐标之名来自他躺床上看苍蝇的故事：沿两面墙的距离加离地高度足以定位。

**向量空间（vector space）**：满足加法交换律、结合律、零向量、负向量、标量乘法分配律等一长串公理的对象集合。重点不是背，而是每条都能画出来：$u+v=v+u$ 就是"先走 u 再走 v"与反过来终点相同，故称交换律或阿贝尔性质（Abel）；$a(u+v)=au+av$ 可用两张缩放图叠合验证。图形学里的多项式、图像、辐射函数（radiance function）看着不像箭头，却遵循同一套规则。

**函数空间（function space）**：逐点定义 $(f+g)(x)=f(x)+g(x)$、$(af)(x)=af(x)$，零向量是处处为零的函数。因为每点取值都落在 $\mathbb{R}$ 中，可直接借用实数的向量空间结构，于是"函数有方向、有长度、能投影"都成为合法说法。

**范数（norm）**：给每个向量指派非负实数，衡量其大小。四条公理：非负；$\|u\|=0$ 当且仅当 $u=0$；$\|cu\|=|c|\,\|u\|$；三角不等式。讲师用"两地距离不可能是负五英里""从 CMU 到 CMU 不可能是两英里"来论证前两条。

**内积（inner product）**：也叫点积、标量积，衡量两个向量方向有多一致。对单位向量，$\langle u,v\rangle$ 就是 v 在 u 上的投影长度；一般情形再乘上长度。性质为对称、正定、对缩放线性、对加法分配，合起来即双线性（bilinear）。

**线性映射与仿射函数（linear / affine map）**：线性映射的几何直觉是直线仍映射为直线且原点不动，代数是 $f(u+v)=f(u)+f(v)$、$f(au)=af(u)$，定义域与陪域维度可以不同。$f(x)=ax+b$ 是陷阱：$f(x_1+x_2)=a(x_1+x_2)+b$，而 $f(x_1)+f(x_2)=a(x_1+x_2)+2b$，差一个 $b$，所以它是仿射函数（affine function）而非线性函数。后面会有把它变成线性映射的技巧（推断：齐次坐标）。

**张成、像与基（span / image / basis）**：张成空间是所有线性组合的集合；线性映射的像就是其列向量张成的空间。$\mathbb{R}^n$ 的基必须恰好是 n 个线性无关向量：少了张不满，方向重复也张不满，多了则坐标不唯一。基不要求正交或单位长度，但标准正交基（orthonormal basis）满足 $\langle e_i,e_j\rangle=\delta_{ij}$，此时 $\sum u_i^2=\|u\|^2$ 才成立。

**格拉姆-施密特与傅里叶基（Gram–Schmidt / Fourier basis）**：前者从任意基造标准正交基——归一化首向量，后续向量减去在已有正交向量上的投影再归一化，重复即可；向量多或近似平行时数值不稳定，实践中常用 QR 分解。后者把周期 $2\pi$ 的函数用 $\cos(nx)$、$\sin(mx)$ 展开，系数就是投影；傅里叶变换本质是一次基变换，把信号从时间/空间基换到频率基。

**线性方程组与自由度（linear system / degrees of freedom, dof）**：未知数是自由度，每个方程是一条约束。几何上既可看作若干仿射子空间的交点，也可看作给定 b 找原像 x。解分存在与唯一两个维度：无解（平行线、b 不在像空间）、唯一解、无穷多解（两方程描述同一约束、$\mathbb{R}^3\to\mathbb{R}^2$ 投影时整条线映到同一点）。

**矩阵（matrix）**：把线性映射编码成数字块。若 $f(u)=u_1a_1+u_2a_2$，把 $a_i$ 作为列拼成 $A$，则 $Au$ 正是"用 u 的分量对 A 的列做线性组合"。讲师视矩阵为"必要的恶"：元素依赖坐标系，同一几何操作在不同基下矩阵完全不同，还容易与二次型混淆；但数值计算最终必须落到矩阵方程。

## 关键公式 / 算法 / 数据结构

逐分量运算：$u+v=(u_1+v_1,\dots,u_n+v_n)$，$au=(au_1,\dots,au_n)$。

中点：$m=\frac{a+b}{2}$，$a=(3,4)$、$b=(7,2)$ 得 $m=(5,3)$。

欧几里得范数：$\|u\|_2=\sqrt{\sum_{i=1}^n u_i^2}$；$u=(4,2)$ 得 $\sqrt{20}=2\sqrt5$。

范数公理：$\|u\|\ge0$；$\|u\|=0\Leftrightarrow u=0$；$\|cu\|=|c|\,\|u\|$；$\|u\|+\|v\|\ge\|u+v\|$。

函数 $L^2$ 范数：$\|f\|_{L^2}=\sqrt{\int_0^1 f(x)^2\,dx}$。

欧几里得内积：$\langle u,v\rangle=\sum_i u_iv_i$，$(4,1)\cdot(1,3)=7$；且 $\langle u,u\rangle=\|u\|^2$。

函数 $L^2$ 内积：$\langle f,g\rangle=\int_0^1 f(x)g(x)\,dx$。

线性映射：$f(u+v)=f(u)+f(v)$，$f(au)=af(u)$。

矩阵表示：$A=[a_1\ \cdots\ a_n]$，$Au=\sum_i u_i a_i$。

Gram–Schmidt：
```
e1 = u1 / ||u1||
for k = 2..n:
    w = uk - Σ_{i<k} <uk, ei> ei
    ek = w / ||w||
```

线性方程组：$\begin{cases}x+2y=3\\4x+5y=6\end{cases}$，得 $x=3-2y$、$y=2$、$x=-1$。

## 讲解脉络

**动机先行。** 先讲为什么值得学：线性代数是几何、物理与计算之间的桥梁，能把问题抽象成线性系统交给高性能求解器；现代图形学的流体、动画、几何处理都跑在数值线性代数上。这为后面忍受公理清单埋下理由。

**从"什么是向量"重建直觉。** 承认箭头图像，追问它编码什么，随即纠正两个误解：向量没有基点；$\theta$ 依赖参考方向，不能与笛卡尔坐标直接比较。再用笛卡尔苍蝇的故事讲分量。接着用首尾相接加法、缩放、分配律三张图反推出公理，再回头对照最初的清单。

**推广到函数，建立范数与内积。** 先验证函数可逐点相加、缩放、有零函数，构成向量空间；再用"哪个函数、哪张图更大"引出范数，用距离例子论证公理，给出欧几里得范数与 $L^2$ 范数。随后用"两张图是否相似"引出内积，从投影解释对称性、齐次性和 $\langle u,u\rangle=\|u\|^2$。最后用"天空 vs 狗"说明范数选择决定算法行为：$L^2$ 偏爱亮而平淡的天空，改用图像梯度的 $L^2$ 范数才能抓到边缘。

**线性映射与仿射的区分。** 先用五边形变形图建立"直线保直线 + 原点不动"的直觉，再给代数定义，并用 $\mathbb{R}^2\to\mathbb{R}^3$ 的"平面被拉伸进三维"解释列向量的线性组合。接着抛出 $f(x)=ax+b$ 的陷阱，用 $b$ 与 $2b$ 不相等证明它不保加法，从而区分 linear 与 affine。

**基、正交化与傅里叶。** 用"哪些向量组能当平面基"的选择题讲清张成、线性无关、唯一坐标三件事，指出基不必正交归一；非正交基下 $\sum u_i^2$ 不再等于长度平方，是代码常见错误。再给 Gram–Schmidt 与数值警告，并把"正交基 + 投影"的思路搬到函数空间，引出正弦/余弦基与傅里叶分解。

**线性方程组与矩阵。** 先手算 2×2 例子，再给三种几何读法（仿射子空间交点、原像、像空间），讨论无解、唯一解、无穷多解，警告不良求解器会"给一堆数字却不说无解"。最后回应"怎么不讲矩阵"：矩阵依赖坐标系、易与二次型混淆，先建立无矩阵的几何理解更重要，但数值计算仍要会写列矩阵。结尾预告向量微积分、特征值、复数，并承认"五边形不等式"的口误，借此鼓励学生质疑。

## 重点结论

- 核心是向量空间与线性映射，矩阵只是某组基下的数值编码；先图景，后矩阵。
- 向量只含方向与大小，不含起点；跨坐标系直接比较数值是经典错误源。
- 向量空间每条公理都能画图解释，不理解来源不算学会。
- 函数、图像、声音都是向量，范数、内积、投影、基全部适用。
- 范数与内积的选择直接决定算法认为"什么重要"：$L^2$ 偏爱亮度，梯度范数偏爱边缘。
- 线性映射 = 保加法 + 保数乘 = 保直线 + 保原点；$ax+b$ 是仿射而非线性。
- 基必须恰好 n 个线性无关向量；非正交归一基会破坏"分量平方和 = 长度平方"。
- 线性系统可能无解或有无穷多解，"求解器返回了数字"不等于"有唯一解"。
- 傅里叶变换本质是基变换，是跨音频、图像、几何、模拟的通用模块。

## 字幕含糊或可能有误的地方

- **"五边形不等式"**：这是讲师自己在结尾承认的口误/玩笑，正确名称是三角不等式（triangle inequality），不是转写错误。
- **$u=(4,2)$ 的范数**：字幕说"根号五"，按 $\sqrt{4^2+2^2}=\sqrt{20}=2\sqrt5$，应是"根号二十"被转写错。
- **$f(x)=\sqrt[3]{x}$ 的 $L^2$ 范数**：字幕写"范数平方 = 积分 $3x^2\,dx$"，积出 $x^3$ 在 $[0,1]$ 上等于 1，故范数为 1。这与所述函数矛盾：$f^2=x^{2/3}$，$\int_0^1x^{2/3}dx=3/5$，范数应为 $\sqrt{3/5}\approx0.775$。判断：公式在转写中严重损坏，"单位范数"的结论不可信。
- **$f=x^2$、$g=1-x^2$ 的内积**：字幕给 $1/30$，按定义 $\int_0^1(x^2-x^4)dx=1/3-1/5=2/15$。判断：数值错，但"很小、几乎不匹配"的定性结论成立。
- **$L^2$ 是否严格满足范数公理**：讲师两次说"这一步有点棘手，希望评论区有人指出"却未展开。判断：他指 $\|f\|_{L^2}=0$ 只能推出 f 几乎处处为零，严格说是半范数、需按等价类处理，这是有意留的伏笔。
- **"从线性方程到二次方程运算时间呈线性增长"**：语义断裂，前后还夹着"NP 难"。判断：原意应是求解难度从线性跳到多项式甚至 NP 难、成本急剧上升，转写把句子打碎，不宜按字面引用。
- **"斯科提"**：指苏格兰梗犬（Scotty），专名音译，不影响理解。字幕中 l²/L² 混用，均指函数空间 $L^2$。
