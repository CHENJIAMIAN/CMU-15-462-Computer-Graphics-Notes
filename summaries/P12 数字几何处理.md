# P12 数字几何处理

## 一句话概括

把信号处理的基本操作——采样、上采样、下采样、滤波、压缩、重采样——从图像音频搬到多边形网格上，讲清"什么样的网格才算好网格"，并给出细分、二次误差简化、Delaunay 边翻转和重网格化四套核心算法。

## 本集主题与目标

上一集解决"几何数据怎么存"（流形假设、半边网格），本集解决"存下来怎么算"。讲师把数字几何处理（digital geometry processing）定位为数字信号处理的下一阶段：传统 DSP 处理图像、音频这类规则网格上的信号，而几何信号是不规则的曲面采样，同样的任务会遇到新困难，也会出现图像处理里没有的新任务（例如把曲面展平到平面做纹理映射）。

本集不追求讲透每个算法，而是先建立一张"任务地图"，再挑最基础的三件事——上采样（细分）、下采样（简化）、重采样（重网格化）——给出可实现细节，并强调"网格质量"这个图像处理里几乎不存在的概念。

## 核心概念

- **流形假设（manifold）**：网格每个局部都能展平成欧几里得平面；等价说法是每个顶点周围只有一个多边形"扇形"、没有鳍状结构，每条内部边恰被两个多边形共享。它让算法能依赖可预测的局部规则，就像图像处理依赖规则像素网格。

- **几何处理管线**：现实物体先被扫描采样成数字表示（点云、带法线的点、线积分数据），再编辑、变换、分析，最后打印回物理世界。它与光栅化管线不同：精度要求更高，且多了"采集"与"制造"两端。

- **重建（reconstruction）**：从样本恢复表面。点云可用 Voronoi 图推断表面，也可用偏微分方程方法；带法线的点或照片提供的轮廓、遮挡信息可用视觉包络；MRI/CT 这类线密度积分数据要先做 Radon 变换，再用 Marching Cubes 提等值面。

- **混叠（aliasing）**：采样不足时，即使采样点精确落在原信号上，重建出的折线仍会给人"平直"的错误印象。几何上同理：顶点全在曲面上，也可能得到错误的法线、面积和曲率。

- **网格质量**：好网格不只是"顶点靠近曲面"。三角形要尽量接近等边（角度接近 60°），顶点度数（valence，接触该顶点的边数）要尽量接近 6。长而细的三角形会让数值模拟出问题，也会让细分产生瑕疵。

- **Delaunay 条件**：每个三角形的外接圆内部不含其他顶点。它按字典序最大化最小角，给出对顶点数据最平滑的线性插值（Rippa 定理），并满足拉普拉斯方程的最大值原理，因此有利于数值稳定与准确。

- **细分（subdivision）**：反复把每个元素切成更小部分，分两步——先改连接性（拓扑），再用邻点加权平均更新位置（几何）。评价方案要看它是插值型还是逼近型、极限曲面几阶连续、在不规则顶点处如何退化。

- **二次误差度量（quadric error metric, QEM）**：用一个 4×4 矩阵累积"到一组平面距离平方和"的二次型，给边折叠打分。任意多个平面的信息被压进一个固定大小的矩阵，这是它高效的关键。

- **边操作三件套**：split（分裂）、flip（翻转）、collapse（坍缩）。它们是实现细分、简化、重网格化的原子操作，配合半边结构只需少量指针重接。

## 关键公式 / 算法 / 数据结构

**点到平面距离与二次型**：平面由单位法向 $n=(a,b,c)$ 与偏移 $d=-n\cdot p$ 表示，齐次点 $u=(x,y,z,1)$、$v=(a,b,c,d)$，则

$$d(x)^2=(u^\top v)^2=u^\top(vv^\top)u=u^\top Ku,\qquad K=vv^\top .$$

多平面求和时矩阵直接相加，故每个顶点只存一个累加的 $K$。

**最优坍缩点**：把 $K$ 分块为 $3\times3$ 的 $B$、$3\times1$ 的 $w$ 和标量，误差写成 $x^\top Bx+2w^\top x+d$，令梯度为零得

$$x^\star=-\tfrac{1}{2}B^{-1}w .$$

只有 $B$ 正定（$x^\top Bx>0$）时才是最小值，否则可能是鞍点，实现中要退化处理。

**Catmull-Clark（四边形主流）**：面点取多边形顶点质心；边点取"两端点 + 两侧面点"平均；顶点点

$$v'=\frac{q+2r+(n-3)s}{n},$$

$n$ 为度数，$q$ 为周围面点平均，$r$ 为周围边点平均，$s$ 为原位置。

**Loop 细分（三角主流）**：每个三角形沿边一分为四；边点取两端点各 $3/8$、对角两点各 $1/8$（和为 1，新点在凸包内）；顶点点用 $u$ 加权邻点、$1-nu$ 保留自身，$n=3$ 时 $u=3/16$，否则 $u=3/(8n)$；规则顶点处曲率连续。

**QEM 简化**：每个三角形算 $K$ 并累加到三个顶点；每条边取 $K_{ij}=K_i+K_j$，解最优点，代价 $=K_{ij}(x^\star)$；用优先队列反复取最小代价边坍缩，更新受影响边的 $K$ 与代价，直到目标面数。

**Delaunay 边翻转**：若一条边两侧对角之和 $\alpha+\beta>\pi$ 就翻转，贪心反复直到所有边满足 $\alpha+\beta\le\pi$。

**重网格化四步**：分裂长于目标长度 $4/3$ 的边；坍缩短于 $4/5$ 的边；翻转边改善顶点度数；把顶点沿切向移到邻点平均位置（切向拉普拉斯平滑，去掉法向分量以免变形）。

## 讲解脉络

1. **回顾定位**：接上一集的流形假设与半边结构，说明"有了数据结构，接下来要操作几何"，把几何处理定义为 DSP 的延伸。

2. **动机与产业背景**：用消费级三维扫描和逐层打印的兔子说明这是"实物→数字→实物"闭环的中间层，并列出管线各阶段。

3. **任务全景**：重建、上采样、下采样、重采样、滤波、压缩、形状分析。每项先类比图像处理，再指出几何特有的难点（连接性数据、单元形状、模型间对应）。这一段是地图，为后面挑重点铺垫。

4. **什么叫好的采样**：用欠采样曲线讲混叠，用带球端盖的圆柱讲"该密的地方密"，再用圆柱的两种三角剖分讲"顶点都在面上也可能错"——棋盘格明暗、面积不一致，引出法线、曲率、单元形状等更高阶要求。

5. **网格质量三条经验法则**：三角形要圆、要满足 Delaunay 空圆、顶点度数接近 6；解释度数与形状、规则计算、细分光滑性的关系，点明"形状好"与"几何逼近好"的权衡，以及球面上不可能处处度数为 6 的拓扑限制。

6. **上采样 = 细分**：先讲评价维度（插值/逼近、连续性、不规则顶点），再给 Catmull-Clark 与 Loop 的权重，用"全三角网格硬跑 Catmull-Clark 会到处是不规则顶点、反射与焦散线变锯齿"说明方案要匹配网格类型；最后用 split + flip 说明如何在半边结构上实现 Loop 的拓扑更新。

7. **下采样 = 简化**：从"随机抽点不好"讲到贪心边折叠，重点推导 QEM（距离→二次型→矩阵可加→最优位置→正定性→完整算法），用颅骨从数万面减到三千、三百、三十面展示效果，最后提醒三角形翻转的检测与回退。

8. **重采样 = 重网格化**：先用反复上下采样一张牛说明重采样会持续退化，再给四步算法；结尾抛出"处理完把顶点投影回原始表面"，引出下一集的几何查询。

## 重点结论

- 几何处理与图像处理同构，但**连接性是图像里没有的额外自由度**，压缩、重采样、滤波都因此变复杂。
- 顶点位置正确 ≠ 表面正确。法线、面积、曲率这些"导数级"属性对三角剖分极其敏感，圆柱例子是最直观证据。
- Delaunay 好在最大化最小角、最平滑插值、满足最大值原理；但它**不保证三角形圆润**（可以全是细长三角形仍满足空圆），所以还需度数优化与拉普拉斯平滑。
- 细分方案要匹配网格类型：四边形用 Catmull-Clark，三角形用 Loop；不规则顶点只继承自原网格，不会被细分"制造"出来，但会让极限曲面降阶。
- QEM 之所以强，是因为误差可写成矩阵和，**历史信息被无损累积进一个 4×4 矩阵**，所以贪心边折叠这种简单启发式也能得到很好的近似。
- 最小化二次型的关键是正定性：正定则解线性方程组即得唯一最小值。这正是"把问题写成能量再解线性系统"这一套路的数学根基。
- 反复重采样必然退化，工程补救是保留原始高精度网格，最后把结果投影回原表面。

## 字幕含糊或可能有误的地方

- **"四象限" / "四次方"**：结合上下文（"二次函数""矩阵 K""距离平方和"）应是 **quadric（二次型）** 的音译误识，不是"象限"或"四次方"。判断：转写错误。
- **"德兰尼 / Delaney / 德莱尼"**：均指 **Delaunay**；"联想 baloney"是讲师给的谐音记忆法，不影响术语。
- **"Ripa 定理"**：应为 **Rippa 定理**（Delaunay 使分段线性插值误差最小）。
- **"四面体简化下的采样"**：从上下文看是 **"二次误差简化下的下采样"**，与四面体无关。
- **"方形根三"**：应为 **$\sqrt{3}$ 细分**；"蝴蝶细分"即 butterfly subdivision，正确。
- **"分割超过平均边长四分之三的边 / 合并短于四分之五的边"**：常见实现用目标长度的 $4/3$ 与 $4/5$，字幕"四分之三"很可能是 $4/3$ 的口误；"四分之五"大于 1 逻辑不通，应为 $4/5$。
- **"导数是 a x 加上 u"**：$x^\top Ax+u^\top x+g$ 的梯度应为 $2Ax+u$，字幕漏了系数 2；后文 $x=-\tfrac12A^{-1}u$ 与之对应，属口误而非概念错误。
- **"红色三角面的法线方向蓝色三角形的法线方向大致相反"**：讲的是折叠后三角形翻转的检测，句子有断裂，应理解为"比较折叠前后相邻三角形的法向，内积为负则放弃这次折叠"。
- **"球面上无法让所有顶点度数为六"**：结论正确，依据是欧拉公式，但字幕没点明，听起来像断言。
